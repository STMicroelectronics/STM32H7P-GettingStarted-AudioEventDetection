HAL CORDIC Typical use cases for migration ¶

This section provides information about the HAL CORDIC Typical use cases for migration.

HAL CORDIC Calculation use cases ¶

Note

The calculation sequence using the HAL CORDIC driver is similar between HAL1 and HAL2:

  • initialization, configuration, and calling the calculation with four modes: polling, zero-overhead, interrupt, and DMA

  • regarding the DMA process:

    • In HAL1 the user specifies the way to handle the input and output data (using the HAL CORDIC driver) or delegates it to another HAL driver, e.g., HAL ADC

    • in HAL2 the user can either use:

      • the function HAL_CORDIC_Calculate_DMA() in this case the input and output data are managed with HAL CORDIC driver itself

      • Or use the functions HAL_CORDIC_Write_DMA() and HAL_CORDIC_Read_DMA() to individually control the CORDIC data streams for write and read directions. in case the read or the write should be managed by another peripheral e.g. ADC, the given HAL_CORDIC function (Read/Write) should be called.

    For more details see HAL CORDIC control functions migration

HAL CORDIC Calculation in DMA mode with peripheral (ADC) ¶

In HAL1, to use the CORDIC peripheral together with another peripheral (such as ADC, Timer, etc.) in DMA mode, you can configure the DMA direction as follows:

CORDIC_DMA_DIR_IN or CORDIC_DMA_DIR_OUT enables one-sided stream management by the CORDIC peripheral. CORDIC_DMA_DIR_NONE allows tow peripherals to Write to and read from CORDIC data registers.

In HAL2, the new functions HAL_CORDIC_Write_DMA and HAL_CORDIC_Read_DMA handle DMA write and read operations separately for improved peripheral management.

In this use case, the ADC performs sampling, conversion and write the result directly to the CORDIC WDATA register using DMA. The CORDIC peripheral then reads only the result, in HAL1 implementing a one-way stream management by setting the DMA direction argument to CORDIC_DMA_DIR_OUT .In HAL2, the read stream is managed using the function HAL_CORDIC_Read_DMA() instead
