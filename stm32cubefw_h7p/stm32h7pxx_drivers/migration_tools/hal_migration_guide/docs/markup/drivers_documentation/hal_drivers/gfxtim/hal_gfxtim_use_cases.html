HAL GFXTIM Typical use cases for migration ¶

This section provides information about the HAL GFXTIM Typical use cases for migration.

Note

The major changes per functional blocks provided in HAL2 are:

  • Clock generator : the clock generator configuration has been split into line configuration and frame configuration.

  • Absolute timer : the absolute timer configuration has been removed and has been managed by unitary functions. The set of line/frame counter APIs is optional and can be configured if needed to start the counter from a different default value instead of zero.

  • Relative timer : the relative counter configuration has been merged with start relative timer API according to the relative mode (continuous or oneshot).

hgfxtim.Instance = GFXTIM;
hgfxtim.Init.SynchroSrc = GFXTIM_SYNC_SRC_HSYNC_VSYNC_0;

                       USER_GFXTIM_ABSTIM_LineCmp1Callback);

                HAL_GFXTIM_ALC_OVERFLOW_CB_ID,
                USER_GFXTIM_ABSTIM_LineCntOverFlowCallback);

 };

                                          &p_frame_config,
                                          &p_line_config);

                                      HAL_GFXTIM_ABSTIM_LINE_COMP_2,
                                      3000U);

                        HAL_GFXTIM_ABSTIM_LINE_COUNTER,
                        HAL_GFXTIM_NONE_IT);

                        HAL_GFXTIM_ABSTIM_LINE_COUNTER,

                         HAL_GFXTIM_ABSTIM_LINE_COUNTER);

/* Disable the absolute line counter */
HAL_GFXTIM_ABSTIM_Stop(&hgfxtim,
                       HAL_GFXTIM_ABSTIM_LINE_COUNTER);
/* GFXTIM Deinitialization */
HAL_GFXTIM_DeInit(&hgfxtim);
