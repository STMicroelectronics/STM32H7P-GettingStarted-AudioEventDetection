#define CORDIC_DMA_DIR_IN_OUT

HAL CORDIC DMA Read/Write enable flags constants ¶

HAL1

HAL2 

#define CORDIC_DMA_REN
#define CORDIC_DMA_WEN

Removed: In HAL2, all DMA request management is handled internally
and does not need to be exported.
To manually control these two bits,, the following APIs can be used:
LL_CORDIC_EnableDMAReq_RD, LL_CORDIC_DisableDMAReq_RD, LL_CORDIC_EnableDMAReq_WR, and LL_CORDIC_DisableDMAReq_WR.

HAL CORDIC status flags constants ¶

HAL1

HAL2 

#define CORDIC_FLAG_RRDY

In HAL1, the defines are used by the macro __HAL_CORDIC_GET_FLAG(__HANDLE__, __FLAG__).

In HAL2, these defines and macros have been removed. Instead, use LL_CORDIC_IsActiveFlag()
  with the LL_CORDIC_FLAG_RRDY parameter, or directly use the function LL_CORDIC_IsActiveFlag_RRDY().

Related concept : All public macros related to hardware (HW) are removed, and equivalent services added to the LL layer.

HAL CORDIC interrupt identifiers constants ¶

HAL1

HAL2 

#define CORDIC_IT_IEN

In HAL1, those defines are used by the __HAL_CORDIC_ENABLE_IT(__HANDLE__, __INTERRUPT__),
  __HAL_CORDIC_DISABLE_IT(__HANDLE__, __INTERRUPT__)
  and __HAL_CORDIC_GET_IT_SOURCE(__HANDLE__, __INTERRUPT__) macros

In HAL2, the IT defines and macros are removed, use LL_CORDIC_EnableIT() and LL_CORDIC_DisableIT() instead .

Related concept : All public macros related to hardware (HW) are removed, and equivalent services added to the LL layer.
