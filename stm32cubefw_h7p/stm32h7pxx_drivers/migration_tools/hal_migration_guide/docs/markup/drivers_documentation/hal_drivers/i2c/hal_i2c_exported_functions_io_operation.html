  • Take a direct pointer to the I2C registers.

  • Manipulate the I2C control register to enable the analog filter.

HAL I2C autonomous mode ¶

  • To configure and enable the I2C autonomous mode uses the functions HAL_I2C_AM_SetConfigTrigge and HAL_I2C_AM_EnableTrigger .

HAL1

HAL2 

I2C_AutonomousModeConfTypeDef sConfig;

sConfig.TriggerState     = I2C_AUTO_MODE_ENABLE;
sConfig.TriggerSelection = I2C_GRP1_GPDMA_CH0_TCF_TRG;
sConfig.TriggerPolarity  = I2C_TRIG_POLARITY_RISING;

HAL_StatusTypeDef HAL_I2CEx_SetConfigAutonomousMode(I2C_HandleTypeDef *hi2c,
                                           const I2C_AutonomousModeConfTypeDef *sConfig)

hal_i2c_am_trigger_config_t p_config;

p_config.source   = HAL_I2C_AM_TRIGGER_GRP1_GPDMA_CH0_TCF;
p_config.polarity = HAL_I2C_AM_TRIGGER_RISING;

hal_status_t HAL_I2C_AM_SetConfigTrigger(hal_i2c_handle_t *hi2c, const hal_i2c_am_trigger_config_t *p_config);
hal_status_t HAL_I2C_AM_EnableTrigger(hal_i2c_handle_t *hi2c);

  • Optionally To get the configuration of I2C autonomous mode and disable it, use the functions HAL_I2C_AM_IsEnabledTrigger and HAL_I2C_AM_DisableTrigger .
