HAL RCC clock recovery system function control ¶

Start synchronization for polling mode ¶

Function Description ¶

The HAL_RCCEx_CRSConfig function is used to configure the Clock Recovery System (CRS). In HAL2, this functionality is split into two functions: HAL_CRS_Init for initialization and HAL_CRS_SetConfig for setting the configuration.

HAL1

HAL2

Function name

void HAL_RCCEx_CRSConfig(const RCC_CRSInitTypeDef *const pInit);

hal_status_t HAL_CRS_Init(hal_crs_handle_t *hcrs, hal_crs_t instance);

Function name

N/A

hal_status_t HAL_CRS_SetConfig(hal_crs_handle_t *hcrs, const hal_crs_config_t *p_config);

Example Usage ¶

HAL1

HAL2 

RCC_CRSInitTypeDef CRSInitStruct;

// Initialize CRS configuration
HAL_RCCEx_CRSConfig(&CRSInitStruct);

hal_crs_handle_t hcrs;
hal_crs_config_t crs_config;
hal_status_t status;

// Initialize CRS
status = HAL_CRS_Init(&hcrs, HAL_CRS_INSTANCE);

// Set CRS configuration
status = HAL_CRS_SetConfig(&hcrs, &crs_config);

HAL RCC CRS Get Synchronization Info ¶

Function Description ¶

The HAL_RCCEx_CRSGetSynchronizationInfo function is used to retrieve synchronization information for the Clock Recovery System (CRS). In HAL2, this functionality is expanded into multiple functions to provide more detailed configuration and status information:

  • HAL_CRS_GetConfig : Retrieves the configuration of a specified CRS instance.

  • HAL_CRS_GetTrimming : Retrieves the current trimming value of the CRS.

  • HAL_CRS_GetFrequencyErrorInfo : Retrieves frequency error information for the CRS.

HAL1

HAL2

Function name

HAL_RCCEx_CRSGetSynchronizationInfo

void HAL_CRS_GetConfig(const hal_crs_handle_t *hcrs, hal_crs_config_t *p_config);

New Function

N/A

uint32_t HAL_CRS_GetTrimming(const hal_crs_handle_t *hcrs);

New Function

N/A

void HAL_CRS_GetFrequencyErrorInfo(const hal_crs_handle_t *hcrs, hal_crs_frequency_error_info_t *p_frequency_error_info);

HAL RCC CRS Wait for synchronization ¶

Function Description ¶

The HAL_RCCEx_CRSWaitSynchronization function is used to wait for the synchronization of the Clock Recovery System (CRS) to complete within a specified timeout. In HAL2, this functionality is provided by the HAL_CRS_PollForSync function, which uses a handle to the CRS instance and specifies the timeout in milliseconds.

HAL1

HAL2

Function name

uint32_t HAL_RCCEx_CRSWaitSynchronization(uint32_t Timeout);

hal_status_t HAL_CRS_PollForSync(hal_crs_handle_t *hcrs, uint32_t timeout_ms);

Example Usage ¶

HAL1

HAL2 

uint32_t timeout = 1000; // Timeout in milliseconds
uint32_t sync_status;

// Wait for CRS synchronization
sync_status = HAL_RCCEx_CRSWaitSynchronization(timeout);

hal_crs_handle_t hcrs;
uint32_t timeout_ms = 1000; // Timeout in milliseconds
hal_status_t status;

// Poll for CRS synchronization
status = HAL_CRS_PollForSync(&hcrs, timeout_ms);

HAL RCC CRS Software Synchronization Generate ¶

Function Description ¶

The HAL_RCCEx_CRSSoftwareSynchronizationGenerate function in HAL1 is used to generate a software synchronization event for the Clock Recovery System (CRS). In HAL2, this functionality is provided by the HAL_CRS_GenerateSoftwareSync function, which uses a handle to the CRS instance to perform the synchronization.

HAL1

HAL2

Function name

void HAL_RCCEx_CRSSoftwareSynchronizationGenerate(void);

hal_status_t HAL_CRS_GenerateSoftwareSync(hal_crs_handle_t *hcrs);

Example Usage ¶

HAL1

HAL2 

// Generate software synchronization for CRS
HAL_RCCEx_CRSSoftwareSynchronizationGenerate();

hal_crs_handle_t hcrs;
hal_status_t status;

// Ensure the CRS handle is properly initialized and in idle state
// Generate software synchronization for CRS
status = HAL_CRS_GenerateSoftwareSync(&hcrs);
