HAL COMP constants migration ¶

This section provides information about the HAL COMP constants migration .

HAL COMP input hysteresis ¶

For some series, we have the following migration :

HAL1

HAL2 

/**/

#define COMP_HYSTERESIS_10MV
#define COMP_HYSTERESIS_20MV
#define COMP_HYSTERESIS_30MV
#define COMP_HYSTERESIS_40MV
#define COMP_HYSTERESIS_50MV
#define COMP_HYSTERESIS_60MV
#define COMP_HYSTERESIS_70MV

typedef enum
{
  HAL_COMP_INPUT_HYSTERESIS_10MV
  HAL_COMP_INPUT_HYSTERESIS_20MV
  HAL_COMP_INPUT_HYSTERESIS_30MV
  HAL_COMP_INPUT_HYSTERESIS_40MV
  HAL_COMP_INPUT_HYSTERESIS_50MV
  HAL_COMP_INPUT_HYSTERESIS_60MV
  HAL_COMP_INPUT_HYSTERESIS_70MV
} hal_comp_input_hysteresis_t;

Example Usage 

COMP_HandleTypeDef *hcomp;
hcomp->Instance = COMP1;
hcomp->Init.Hysteresis = COMP_HYSTERESIS_10MV;
/*initialize the other Init structure mombres */
...
HAL_COMP_Init(hcomp);

Example Usage 

hal_comp_config_t *comp_config;
HAL_COMP_Init(COMP1);
comp_config->input_hysteresis = HAL_COMP_INPUT_HYSTERESIS_10MV;
/*initialize the other structure mombres of hal_comp_config_t */
...
HAL_COMP_SetConfig(COMP1, comp_config);

For the other series, we have the migration below :

HAL1

HAL2 

/**/

#define COMP_HYSTERESIS_NONE
#define COMP_HYSTERESIS_LOW
#define COMP_HYSTERESIS_MEDIUM
#define COMP_HYSTERESIS_HIGH

typedef enum
{
  HAL_COMP_INPUT_HYSTERESIS_NONE
  HAL_COMP_INPUT_HYSTERESIS_LOW
  HAL_COMP_INPUT_HYSTERESIS_MEDIUM
  HAL_COMP_INPUT_HYSTERESIS_HIGH

} hal_comp_input_hysteresis_t;

Example Usage 

COMP_HandleTypeDef *hcomp;
hcomp->Instance = COMP1;
hcomp->Init.Hysteresis = COMP_HYSTERESIS_NONE;
/*initialize the other Init structure mombres */
...
HAL_COMP_Init(hcomp);

Example Usage 

hal_comp_config_t *comp_config;

HAL_COMP_Init(COMP1);
comp_config->input_hysteresis = HAL_COMP_INPUT_HYSTERESIS_NONE;
/*initialize the other structure mombres of hal_comp_config_t */
...
HAL_COMP_SetConfig(COMP1, comp_config);

Summary of key changes

  1. Conversion to enumerated type:

    The HAL COMP input hysteresis, which were previously defined using #define constant , have been converted to an enumerated type (enum).

  2. Renaming for Consistency:

    The constants have been renamed to follow a consistent naming convention, prefixed with HAL_COMP_INPUT_HYSTERESIS_ .

Related concepts: Replace Finite Parameter Defines (Including PPP Instances) with Enum Types at HAL Levels.
