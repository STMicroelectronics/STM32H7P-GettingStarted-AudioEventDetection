HAL FMAC Typical use cases for migration ¶

This section provides information about the HAL FMAC Typical use cases for migration.

  • On the FMAC peripheral, both input and output operations can be configured using a variety of modes, including Polling, Interrupt, DMA, or handled by external Peripheral. These modes can be independently selected for input and output, allowing for flexible combinations between FIFO input writing and FIFO output reading (as shown in the table of typical combinations).

  • In HAL1, these modes were configured using the InputAccess and OutputAccess fields within the FMAC_FilterConfigTypeDef structure.

  • In HAL2, input data management is performed through the following APIs:

    • HAL_FMAC_WriteX1()

    • HAL_FMAC_WriteX1_IT()

    • HAL_FMAC_WriteX1_DMA()

    • HAL_FMAC_WriteX1_DMA_Opt()

When delegating input data handling to another peripheral, these WriteX1 APIs are not called directly.

  • Similarly, output data management uses the APIs:

    • HAL_FMAC_ReadY()

    • HAL_FMAC_ReadY_IT()

    • HAL_FMAC_ReadY_DMA()

    • HAL_FMAC_ReadY_DMA_Opt()

If output data handling is assigned to another peripheral, the ReadY APIs are not called directly either.

FIR or IIR Interrupt input/X1, DMA output/Y ¶

  • In the following use case the input X1 FIFO is managed with interrupt process, and the output Y FIFO is managed with DMA process

sFmacConfig.x2_buf.size_half_word = COEFFICIENT_BUFFER_SIZE;

data.coeff_a_size_half_word = COEFF_VECTOR_A_SIZE;

data.p_coeff_b              = aFilterCoeffB;

HAL_FMAC_Write_IT(&hfmac, Input);
HAL_FMAC_ReadY_DMA(&hfmac, Output, OutputDataSize);

HAL_FMAC_StopFilter(&hfmac);

HAL_FMAC_DeInit(&gh_fmac);

FIR or IIR PERIPH ADC input/X1, DMA output/Y ¶

  • In the following use case, the X1 FIFO input is fed by the ADC driver using ADC APIs that sample data for the FMAC driver managed by ADC, and the Y FIFO output is managed by the DMA process.
