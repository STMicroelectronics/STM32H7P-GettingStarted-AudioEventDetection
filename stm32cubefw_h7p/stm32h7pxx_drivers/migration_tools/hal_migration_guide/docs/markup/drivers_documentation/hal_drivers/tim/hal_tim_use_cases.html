HAL TIM Typical use cases for migration ¶

Specific TIM Concept ¶

HAL1 vs HAL2 Initialization ¶

Functionality

HAL1

HAL2

Initialization

  • In HAL1, each process has its own initialization function. To initialize any functionalities of the Timer (TIM) peripheral, you need to call specific functions for each functionality:

    • HAL_TIM_Base_Init(&htim) for the TIM time base .

    • HAL_TIM_PWM_Init(&htim) for the TIM PWM time base .

    • HAL_TIM_OC_Init(&htim) for the TIM output compare time base .

    • HAL_TIM_IC_Init(&htim) for the TIM input capture time base .

    • HAL_TIM_OnePulse_Init(&htim, OnePulseMode) for the TIM one-pulse time base .

    • HAL_TIM_Encoder_Init(&htim, &sConfig) for the TIM encoder interface initialization .

    • HAL_TIMEx_HallSensor_Init(&htim, &sConfig) for the TIM Hall sensor interface initialization .

  • In contrast, HAL2 simplifies this process by replacing all these individual initialization functions with a single function followed by a configuration function:

    • HAL_TIM_Init(&htim, HAL_TIMi)

    • HAL_TIM_SetConfig(&htim, &p_config)

    Important

    In HAL1, the functions HAL_TIM_OnePulse_Init , HAL_TIM_Encoder_Init , and HAL_TIMEx_HallSensor_Init include additional configurations beyond the basic setup. Therefore, in HAL2, in addition to HAL_TIM_Init and HAL_TIM_SetConfig , other functions must be called to achieve the same behavior as in HAL1.

HAL1 vs HAL2 Deinitialization ¶

Functionality

HAL1

HAL2

Deinitialization

  • Similarly to Initialization, HAL1 requires individual deinitialization functions for each process:

    • HAL_TIM_Base_DeInit(&htim) for the base timer.

    • HAL_TIM_OC_DeInit(&htim) for the output compare.

    • HAL_TIM_PWM_DeInit(&htim) for the PWM.

    • HAL_TIM_IC_DeInit(&htim) for the input capture.

    • HAL_TIM_OnePulse_DeInit(&htim) for the one-pulse mode.

    • HAL_TIM_Encoder_DeInit(&htim) for the encoder interface.

    • HAL_TIMEx_HallSensor_DeInit(&htim) for the Hall sensor.

  • In HAL2, the deinitialization process is simplified with a single function for all processes:

    • Deinitialize the timer using HAL_TIM_DeInit(&htim) .

HAL1 vs HAL2 Start and Stop ¶

Functionality

HAL1

HAL2

Start and Stop

  • In HAL1, each process has its own function for start and stop:

    • HAL_TIM_Base_Start/IT/DMA

    • HAL_TIM_Base_Stop/IT/DMA

    • HAL_TIM_OC_Start/IT/DMA

    • HAL_TIM_OC_Stop/IT/DMA

    • HAL_TIMEx_OCN_Start/IT/DMA

    • HAL_TIMEx_OCN_Stop/IT/DMA

    • HAL_TIM_PWM_Start/IT/DMA

    • HAL_TIM_PWM_Stop/IT/DMA

    • HAL_TIMEx_PWMN_Start/IT/DMA

    • HAL_TIMEx_PWMN_Stop/IT/DMA

    • HAL_TIM_IC_Start/IT/DMA

    • HAL_TIM_IC_Stop(&htim)

    • HAL_TIM_OnePulse_Start/IT

    • HAL_TIM_OnePulse_Stop/IT

    • HAL_TIMEx_OnePulse_Start/IT

    • HAL_TIMEx_OnePulse_Stop/IT

    • HAL_TIM_Encoder_Start/IT/DMA

    • HAL_TIM_Encoder_Stop/IT/DMA

    • HAL_TIMEx_HallSensor_Start/IT/DMA

    • HAL_TIMEx_HallSensor_Stop/IT/DMA

  • In HAL2, depending on the function to be performed by the timer and depending on the way the channel is used, either output or input, there are specific functions to use:

    • If the process is for simple Time base:

      • HAL_TIM_Start/IT/DMA

      • HAL_TIM_Stop/IT/DMA

    • If the process is for an output compare, we call upon the function that allows starting the channel process in output mode:

      • HAL_TIM_OC_StartChannel/IT/DMA/DMA_opt

      • HAL_TIM_Start

    • If the process is for an input capture, we call upon the function that allows starting the channel process in input mode:

      • HAL_TIM_IC_StartChannel/IT/DMA/DMA_opt

      • HAL_TIM_Start

    Note

    DMA_opt is a new feature in HAL2 that allows configuring the DMA optionally, i.e., configuring the DMA with the possibility of not generating an interruption.

HAL1 vs HAL2 Channel Configuration ¶

Functionality

HAL1

HAL2

Channel Configuration

  • In HAL1, each process has its own function for channel configuration:

    • HAL_TIM_OC_ConfigChannel

    • HAL_TIM_PWM_ConfigChannel

    • HAL_TIM_IC_ConfigChannel

    • HAL_TIM_OnePulse_ConfigChannel

  • In HAL2, depending on the way the channel is used, either output or input, there are specific functions to use:

    • If the channel is used for output:

      • HAL_TIM_OC_SetConfigChannel

      • HAL_TIM_OC_SetConfigCompareUnit

    • If the channel is used for input:

      • HAL_TIM_IC_SetConfigChannel

      • HAL_TIM_IC_SetConfigCaptureUnit

TIM use cases ¶

Time Base in interrupt mode ¶

Functionality

HAL 1

HAL 2

Start TIMx in IT mode

  • The function HAL_TIM_Base_Start_IT() is used to enable :

    • The TIMx peripheral.

    • The update event interrupt

  • The function HAL_TIM_Start_IT() is used to enable :

    • The TIMx peripheral.

    • The update event interrupt

TIMx IRQ handler

  • Inside the interrupt handler for TIMx user call The The global IRQ handler of TIM driver HAL_TIM_IRQHandler() to handle the update interrupt request.

  • Inside the interrupt handler for TIMx, the user can call either:

    • The global IRQ handler HAL_TIM_IRQHandler() to handle the TIMx interrupt request, or

    • The single process IRQ handler for specific interrupt events in this case HAL_TIM_UPD_IRQHandler() .

Callback function

  • The function HAL_TIM_PeriodElapsedCallback() is called when the period elapses.

  • The function HAL_TIM_UpdateCallback() is called when the period elapses.

Sequence diagram ¶

Note

The unique differences between HAL1 and HAL2 in the time base interrupt mode use case are the initialization sequence, the TIM Start API naming, and the update callback API naming.

PWM Output in interrupt mode ¶

Functionality

HAL 1

HAL 2

Channel Configuration

  • In HAL1 to initializes the TIM PWM channels according to the specified parameters you need to call:

    • HAL_TIM_PWM_ConfigChannel .

  • In HAL2 just replace by the following sequence:

    • HAL_TIM_OC_SetConfigChannel

    • HAL_TIM_OC_SetConfigCompareUnit

Start the pwm signal in IT mode

  • The function HAL_TIM_PWM_Start_IT(&htim, TIM_CHANNEL_x) is used to enable:

    • The TIMx peripheral.

    • The selected channel x .

    • The capture compare x interrupt.

  • The function HAL_TIM_OC_StartChannel_IT(&htim, TIM_CHANNEL_x) is used to enable :

    1. The selected channel x .

    2. The capture compare x interrupt.

  • The function HAL_TIM_Start() is used to enable and start the TIMx.

TIMx IRQ handler

  • Inside the interrupt handler for TIMx user call The The global IRQ handler of TIM driver HAL_TIM_IRQHandler() to handle the capture compare x interrupt request.

  • Inside the interrupt handler for TIMx, the user can call either:

    • The global IRQ handler HAL_TIM_IRQHandler() to handle the capture compare x interrupt request, or

    • The single process IRQ handler for specific interrupt events in this case HAL_TIM_CC_IRQHandler() .

Callback function

  • The function HAL_TIM_PWM_PulseFinishedCallback() is called when the PWM pulse is finished.

  • The function HAL_TIM_CompareMatchCallback() is called when the output compare event occurs.

Important

When using PWM with DMA, it is mandatory to call the function HAL_TIM_OC_EnableChannelComparePreload .

External Trigger Synchro ¶

This example shows how to synchronize TIM peripherals in cascade mode with an external trigger. In this example three timers are used:

  • TIM1 is slave for an external Trigger and master for TIM2.

  • TIM2 is slave for TIM1.

Functionality

HAL 1

HAL 2

Initialize and configure timers

  • After initialization and basic configuration for TIMx, configure TIMx as Master or as Slave Timer using the following functions:

    • HAL_TIM_SlaveConfigSynchro to configure slave mode.

    • HAL_TIMEx_MasterConfigSynchronization to configure master mode.

    • HAL_TIM_OC_ConfigChannel to configure the output channel.

  • Similarly, in HAL2, after initialization and basic configuration for each timer, we need to call the following function to configure each timer in the appropriate mode.

  • To configure the slave mode .

  • To configure the master mode.

  • To configure the output channel.

Start timers

  • HAL_TIM_IC_Start(&htim1, TIM_CHANNEL_2) is used to capture the external trigger.

  • HAL_TIM_OC_Start(&htim1, TIM_CHANNEL_1) is used as Trigger Output for TIM2.

  • HAL_TIM_OC_Start(&htim2, TIM_CHANNEL_1) is used to generate a signal.

  • HAL_TIM_IC_StartChannel(&htim1, HAL_TIM_CHANNEL_2) is used to capture the external trigger.

  • HAL_TIM_OC_StartChannel(&htim1, HAL_TIM_CHANNEL_1) is used as Trigger Output for TIM2.

  • HAL_TIM_OC_StartChannel(&htim2, HAL_TIM_CHANNEL_1) is used to generate a signal.

  • HAL_TIM_Start(&htim1) is used to start TIM1.

  • HAL_TIM_Start(&htim2) is used to start TIM2.
