HAL GFXTIM interrupt enable/disable constants ¶

HAL1

HAL2

In HAL1, the interrupt is a member of the configuration structure for each functional block (absolute timer, relative timer, tearing effect detection, event generator and watchdog counter).

In HAL2, the interrupt is managed directly through the start APIs of each functional block. 

#define GFXTIM_IT_DISABLE

#define GFXTIM_IT_ENABLE

#define HAL_GFXTIM_NONE_IT

#define HAL_GFXTIM_ABSTIM_LINE_COMP1_IT
#define HAL_GFXTIM_ABSTIM_LINE_COMP2_IT
#define HAL_GFXTIM_ABSTIM_LINE_COUNT_OVERFLOW_IT
#define HAL_GFXTIM_ABSTIM_LINE_ALL_IT
#define HAL_GFXTIM_ABSTIM_FRAME_COMP_IT
#define HAL_GFXTIM_ABSTIM_FRAME_COUNT_OVERFLOW_IT
#define HAL_GFXTIM_ABSTIM_FRAME_ALL_IT
#define HAL_GFXTIM_RELTIM_COUNT_IT
#define HAL_GFXTIM_TEARING_EFFECT_IT
#define HAL_GFXTIM_EVENTGEN_EVENT_IT
#define HAL_GFXTIM_WDG_PREALARM_IT
#define HAL_GFXTIM_WDG_ALARM_IT

HAL GFXTIM operating modes constants ¶

HAL2

#define GFXTIM_MODE_CONTINUOUS

HAL GFXTIM synchronization sources constants ¶

HAL1

HAL2

In HAL1, the synchronization source is member of GFXTIM_InitTypeDef. It provides all possible interconnections sources.

In HAL2, hal_gfxtim_sync_src_t provides only the connected synchronization source. It is available in some stm32 devices. For example, in U5 this enumeration is not available because the LTDC is the only connected synchronization source. 

/* */

 #define GFXTIM_SYNC_SRC_HSYNC_VSYNC_0
