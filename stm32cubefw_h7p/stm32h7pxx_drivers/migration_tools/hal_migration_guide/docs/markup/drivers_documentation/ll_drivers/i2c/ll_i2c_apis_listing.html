LL I2C APIs listing for migration ¶

There are a few API changes in the LL layer. This page lists only the modified LL APIs. Others not listed here are unchanged between HAL1 and HAL2.

APIs that retain their original name and functionality ,executing the same operations on the identical registers and bit fields , but have updated function signatures are not listed .

For exemple :

HAL1

HAL2 

__STATIC_INLINE void LL_I2C_SetOwnAddress2(I2C_TypeDef *I2Cx, uint32_t OwnAddress2);

__STATIC_INLINE void LL_I2C_SetOwnAddress2(I2C_TypeDef *p_i2c, uint32_t own_address2, uint32_t own_addr_mask);
