HAL SDRAM types migration ¶

This section provides information about the HAL SDRAM types migration.

HAL SDRAM enumeration type definition ¶

HAL SDRAM callback ID enumeration ¶

HAL1

HAL2 

typedef enum
{
  HAL_SDRAM_MSP_INIT_CB_ID,
  HAL_SDRAM_MSP_DEINIT_CB_ID,
  HAL_SDRAM_REFRESH_ERR_CB_ID,
  HAL_SDRAM_DMA_XFER_CPLT_CB_ID,
  HAL_SDRAM_DMA_XFER_ERR_CB_ID,
} HAL_SDRAM_CallbackIDTypeDef;

Removed: The callback registration in HAL2 is handled by specific functions.

Note

  • HAL_SDRAM_MSP_INIT_CB_ID : Removed . No more MSP, they are replaced by a user sequence.

  • HAL_SDRAM_MSP_DEINIT_CB_ID : Removed . No more MSP, they are replaced by a user sequence.

  • HAL_SDRAM_REFRESH_ERR_CB_ID : Use directly HAL_SDRAM_RegisterRefreshErrorCallback() .

  • HAL_SDRAM_DMA_XFER_CPLT_CB_ID : Removed . No more Read/Write APIs in HAL SDRAM, use HAL DMA APIs.

  • HAL_SDRAM_DMA_XFER_ERR_CB_ID : Removed . No more Read/Write APIs in HAL SDRAM, use HAL DMA APIs.

Related concepts : Remove MspInit and MspDeInit callbacks

  /* --------------- */

Note

  • HAL_SDRAM_STATE_BUSY is replaced with HAL_SDRAM_DEVICE_STATE_ACTIVE for each device.

  • HAL_SDRAM_STATE_ERROR is removed (No more Read/Write APIs use in HAL SDRAM driver).

  • HAL_SDRAM_STATE_WRITE_PROTECTED is removed , no more state to reflect the SDRAM write protection instead use the function HAL_SDRAM_IsEnabledWriteProtection() to know if the sdram is write protected.

  • HAL_SDRAM_STATE_READY is replaced with HAL_SDRAM_DEVICE_STATE_MEMORY_IDLE for each device.

  • HAL_SDRAM_STATE_PRECHARGED is removed , same use as HAL_SDRAM_DEVICE_STATE_MEMORY_IDLE .

HAL SDRAM FMC command structure ¶

Note

The CommandTarget represent the device that is targeted in HAL2. It is passed as

HAL1

HAL2

The CommandTarget ( FMC_SDRAM_CMD_TARGET_BANK1 , FMC_SDRAM_CMD_TARGET_BANK2 ) is set in the command structure.

The Device ( HAL_SDRAM_DEVICE1 , HAL_SDRAM_DEVICE2 ) replace the CommandTarget and passed as API parameter to HAL_SDRAM_SendCommand() . 

typedef struct
{
  uint32_t CommandMode;
  uint32_t CommandTarget;
  uint32_t AutoRefreshNumber;
  uint32_t ModeRegisterDefinition;
} FMC_SDRAM_CommandTypeDef;

typedef struct
{
  hal_sdram_command_code_t command;
  /* CommandTarget is passed as API parameter */
  uint32_t parameter;
  /* ------------- */
} hal_sdram_command_t;

Note

  • See FMC Command Mode , FMC command target .

  • In HAL1, the AutoRefreshNumber and ModeRegisterDefinition parameters are given explicitly in the structure. These parameters are used exclusively and respectively in HAL_SDRAM_COMMAND_AUTOREFRESH and HAL_SDRAM_COMMAND_LOAD .

  • In HAL2, these parameters are replaced by one single parameter that represent AutoRefreshNumber in case of HAL_SDRAM_COMMAND_AUTOREFRESH and ModeRegisterDefinition in case of HAL_SDRAM_COMMAND_LOAD .
