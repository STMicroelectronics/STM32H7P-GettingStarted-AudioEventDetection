HAL RCC constants migration ¶

This section provides information about the HAL RCC constants migration .

HAL RCC HSE Configuration ¶

HAL1

HAL2 

#define RCC_HSE_OFF


#define RCC_HSE_ON
#define RCC_HSE_BYPASS
#define RCC_HSE_BYPASS_DIGITAL

/* unitary API is provided in HAL2 to cover this feature ``HAL_RCC_HSE_Disable()`` */
 typedef enum
 {
   HAL_RCC_HSE_ON
   HAL_RCC_HSE_BYPASS
   HAL_RCC_HSE_BYPASS_DIGITAL
 } hal_rcc_hse_t;

Related concept: HAL defines and enum(those used for HW registers) are redirected to the equivalent LL ones.
