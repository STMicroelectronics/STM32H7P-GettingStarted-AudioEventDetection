HAL DMA typical use cases for migration ¶

Note

  • For U5 and H5 series : The multiplier is 1 because HAL APIs work with bytes .

  • For C0, L4, G4, and G0 series : The multiplier depends on the source data size since HAL APIs work with beats (same as the source data width). Users need to adjust the data size by multiplying it by the multiplier according to the source data size. For example, if the source data size is a word, the data size needs to be multiplied by 4 .

DMA channel linear linked-list mode transfer : polling mode ¶

Note

To perform a DMA linked-list transfer, follow these steps:

  • First, fill the desired nodes with the required configuration.

  • Next, create a queue using these filled nodes.

  • Finally, start the transfer using the built queue.

HAL2 

HAL_DMAEx_List_BuildNode(&NodeConf, &Node1);

HAL_DMAEx_List_InsertNode(&Queue1, NULL, &Node1);


HAL_DMAEx_List_Init(&LL_HandleDMA1);


HAL_DMAEx_List_LinkQ(&LL_HandleDMA1, &Queue1);

HAL_DMAEx_List_Start(&LL_HandleDMA1)


HAL_DMA_PollForTransfer(&hdma_F, HAL_DMA_FULL_TRANSFER, timeout);

HAL_DMA_FillNodeConfig(Node1, NodeConf, HAL_DMA_NODE_2D_ADDRESSING);

HAL_Q_Init(Queue2, &HAL_DMA_2DAddressing_DescOps);
HAL_Q_InsertNode(Queue2, NULL, Node1);

HAL_DMA_Init(LL_DMA_Handle1, HAL_GPDMA1_CH12);
HAL_DMA_SetConfigLinkedListXfer(LL_DMA_Handle1, LL_xfer_config1);



HAL_DMA_StartLinkedListXfer(&hdma, srcAddress, dstAddress, dataSize * multiplier);


HAL_DMA_PollForXfer(&hdma, HAL_DMA_XFER_FULL_COMPLETE, timeout);

Related examples in HAL2 ¶

Example Name

Description

example_hal_dma_data_handling

How to use the DMA Controller to do data handling between transferred data from the source and transfer to the destination through the HAL API.

example_hal_dma_linked_list

How to use the DMA to perform a list of transfers. The transfer list is organized as linked-list, each time the current transfer ends the DMA automatically reload the next transfer parameters, and starts it (without CPU intervention).

How to configure and use the DMA HAL API to perform repeated block transactions.
