HAL USART constants migration ¶

This section provides information about the HAL USART constants migration.

HAL USART error ¶

HAL1

HAL2

In HAL1, error handling is performed using a set of macros that define various error states, including combined errors such as HAL_USART_ERROR_DMA .

In HAL2, the error defines are reorganized and renamed.

  • The HAL_USART_ERROR_DMA are split into separate transmit and receive error defines.

  • The HAL_USART_ERROR_INVALID_CALLBACK is removed. for more details see HAL_USART_GetError 

#define HAL_USART_ERROR_NONE
#define HAL_USART_ERROR_PE
#define HAL_USART_ERROR_NE
#define HAL_USART_ERROR_FE
#define HAL_USART_ERROR_ORE
#define HAL_USART_ERROR_RTO
#define HAL_USART_ERROR_UDR

#define HAL_USART_ERROR_DMA


#define HAL_USART_ERROR_INVALID_CALLBACK

#define HAL_USART_ERROR_NONE
#define HAL_USART_RECEIVE_ERROR_PE
#define HAL_USART_RECEIVE_ERROR_NE
#define HAL_USART_RECEIVE_ERROR_FE
#define HAL_USART_RECEIVE_ERROR_ORE
#define HAL_USART_RECEIVE_ERROR_RTO
#define HAL_USART_RECEIVE_ERROR_UDR

#define HAL_USART_RECEIVE_ERROR_DMA
#define HAL_USART_TRANSMIT_ERROR_DMA

Related concepts: Revise and optimize HAL error management.

Note

For the following USART constants, which were previously defined using #define macros, have been converted to an enumerated type (enum). Related concept: Replace Finite Parameter Defines (Including PPP Instances) with Enum Types at HAL Levels.

HAL USART autonomous mode ¶

HAL1

HAL2 

/* */





#define USART_AUTONOMOUS_MODE_DISABLE


#define USART_AUTONOMOUS_MODE_ENABLE

The constants for managing the USART autonomous mode are removed because enabling or disabling the autonomous mode is no longer handled within the USART_AutonomousModeConfTypeDef . Instead, use the following functions to manage the autonomous mode: 

// To enable the USART autonomous mode packet trigger
hal_status_t HAL_USART_AM_EnablePacketTrigger(const hal_usart_handle_t *husart)

// To disable the USART autonomous mode packet trigger
hal_status_t HAL_USART_AM_DisablePacketTrigger(const hal_usart_handle_t *husart)

HAL2 

#define USART_CLOCK_DISABLE

In HAL2, the user can select the mode () through HAL_USART_SetConfig() or HAL_USART_SetMode() .
