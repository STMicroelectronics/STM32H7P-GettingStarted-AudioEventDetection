LL RTC APIs listing for migration ¶

There are several API changes in the LL layer. This page lists only the modified LL APIs; those not mentioned remain unchanged between HAL1 and HAL2.

APIs that keep their original name and functionality—performing the same operations on the same registers and bit fields—but have updated function signatures are not listed. In HAL2, the explicit RTC instance parameter has been removed because there is only one RTC instance.

For example:

HAL1

HAL2 

__STATIC_INLINE void LL_RTC_ALMA_SetMinute(RTC_TypeDef *RTCx,
                                           uint32_t Minutes)

__STATIC_INLINE void LL_RTC_ALMA_SetMinute(uint32_t Minutes)
