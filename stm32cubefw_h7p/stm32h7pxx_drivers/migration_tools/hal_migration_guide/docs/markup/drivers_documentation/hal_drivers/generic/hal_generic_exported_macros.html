HAL DBGMCU Migration Macros ¶

Freeze and Unfreeze Peripherals ¶

HAL1

HAL2

Description

In HAL1, freezing and unfreezing the clock of various peripherals was done using preprocessor macros.

In HAL2, this functionality has been encapsulated into a new DBGMCU driver with static inline functions for a more structured approach.

Example 

#define __HAL_DBGMCU_FREEZE_<PERIPHERAL>()
#define __HAL_DBGMCU_UNFREEZE_<PERIPHERAL>()

__STATIC_INLINE void HAL_DBGMCU_<PERIPHERAL>_Freeze(void)
__STATIC_INLINE void HAL_DBGMCU_<PERIPHERAL>_UnFreeze(void)

Example with TIM3

HAL1

HAL2 

#define __HAL_DBGMCU_FREEZE_TIM3()
#define __HAL_DBGMCU_UNFREEZE_TIM3()

__STATIC_INLINE void HAL_DBGMCU_TIM3_Freeze(void)
__STATIC_INLINE void HAL_DBGMCU_TIM3_UnFreeze(void)

Check and Clear SBS Memories Erase Status Flags ¶

Check SBS Memories Erase Status Flags

In HAL2, this functionality is encapsulated into separated static inline functions for each flag,

declared in the Low Layer (LL).

HAL1

HAL2

Example 

#define __HAL_SBS_GET_MEMORIES_ERASE_STATUS(__FLAG__)

__STATIC_INLINE uint32_t LL_SBS_IsActiveFlag_IPMEE(void)
__STATIC_INLINE uint32_t LL_SBS_IsActiveFlag_MCLR(void)

Clear SBS Memories Erase Status Flags

In HAL2, this functionality is encapsulated into separated static inline functions for each flag,

declared in the Low Layer (LL).

HAL1

HAL2

Example 

#define __HAL_SBS_CLEAR_MEMORIES_ERASE_STATUS(__FLAG__)

__STATIC_INLINE void LL_SBS_ClearFlag_IPMEE(void)
__STATIC_INLINE void LL_SBS_ClearFlag_MCLR(void)

Related concept : All public macros related to hardware (HW) are removed, and equivalent services added to the LL layer.
