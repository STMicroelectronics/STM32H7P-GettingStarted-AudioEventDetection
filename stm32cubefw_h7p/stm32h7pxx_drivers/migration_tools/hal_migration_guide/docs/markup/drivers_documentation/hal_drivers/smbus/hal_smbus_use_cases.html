HAL SMBUS Typical use cases for migration ¶

Note

The processes for transmitting and receiving data using interrupt are the same in HAL1 and HAL2, except for the specification of buffer size: HAL1 uses Size for the number of data elements (u16), while HAL2 uses Size_byte for the buffer size in bytes.
