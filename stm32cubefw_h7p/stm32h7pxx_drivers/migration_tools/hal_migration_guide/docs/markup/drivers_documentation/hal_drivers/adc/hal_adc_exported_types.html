Removed.

Note

The callback registration in HAL2 is handled by specific functions for each ADC event.

The update from HAL 1 to HAL 2 involves a significant change in the way callback functions are registered for ADC events.

Related concept : Split Global Register callback API to one register API per callback and remove unregister callback API
