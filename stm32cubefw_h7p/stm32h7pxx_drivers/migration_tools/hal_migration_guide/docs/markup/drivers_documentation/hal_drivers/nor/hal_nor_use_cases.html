HAL NOR Typical use cases for migration ¶

This section provides information about the HAL NOR Typical use cases for migration.

Important

The HAL NOR support 16 bits memory only. 8 bits memory support will be added later.

Important

In HAL2, more APIs and CFI commands are added, to learn more about the usage please check the HAL2 documentation.

Important

Most of the APIs are split according to the command set of the device.

For HAL1 , the command sets are read and saved by the driver internally.

For HAL2 , “HAL_NOR_CFI_000x” must be used to execute the requested command:

  • “HAL_NOR_CFI_0001” for Command Set ID 0001 (Intel/Sharp Extended).

  • “HAL_NOR_CFI_0002” for Command Set ID 0002 (AMD/Fujitsu Standard).

  • “HAL_NOR_CFI_0003” for Command Set ID 0003 (Intel Standard).

Program and Read operations ¶

HAL1

HAL2

The HAL NOR driver is designed to use high level API that abstracts the CFI commands .

The HAL NOR driver provider the user with CFI 0001, 0002, 0003 APIS for program and read.

Note

In HAL1, the program API pass the data to be written by address. IN HAL2, The APIs pass the data by value as we are using one data at a time.

HAL1

HAL2 

/* Program API */
HAL_NOR_Program(&hnor,
                (uint32_t *)NOR_StartAddress,
                &program_data
                /* --- */
               );
HAL_NOR_ReturnToReadMode(&hnor);
/* Read API */
HAL_NOR_ReadBuffer(&hnor,
                   (uint32_t *)NOR_StartAddress,
                   read_data_buffer,
                   buffer_size
                  );

/* Program API for command set ID 0001 */
HAL_NOR_CFI_0001_Program(&hnor,
                         (uint32_t *)NOR_StartAddress,
                         program_data,
                         1000 // 1000 ms
                        );
HAL_NOR_CFI_0001_Reset(&hnor);
/* Read API for command set ID 0001 */
HAL_NOR_CFI_0001_ReadArray(&hnor,
                           (uint32_t *)NOR_StartAddress,
                           read_data_buffer,
                           buffer_size
                          );

Read operations of CFI information ¶

HAL1

HAL2

The user read the CFI information using:

  • HAL_NOR_Read_CFI() .

then return to read mode using:

  • HAL_NOR_ReturnToReadMode() .

The user read the CFI information using:

  • HAL_NOR_CFI_ReadDeviceInfo() .

then reset the device to return to read mode using:

  • HAL_NOR_CFI_000x_Reset() . 

NOR_HandleTypeDef hnor;
NOR_CFITypeDef nor_cfi;
/* Read CFI info */
HAL_NOR_Read_CFI(&hnor, &nor_cfi);
/* Return to read mode */
HAL_NOR_ReturnToReadMode(&hnor);
/* Read data from the NOR flash memory */
HAL_NOR_ReadBuffer(&hnor,
                   (uint32_t *)NOR_StartAddress,
                   read_data_buffer,
                   buffer_size
                  );

hal_nor_handle_t hnor;
hal_nor_cfi_device_info_t device_info;
/* Retrieve NOR flash CFI information */
HAL_NOR_CFI_ReadDeviceInfo(&hnor, &device_info);
/* Reset the NOR flash device */
HAL_NOR_CFI_0001_Reset(&hnor);
/* Read data from the NOR flash memory */
HAL_NOR_CFI_0001_ReadArray(&hnor
                           (uint32_t *)NOR_StartAddress,
                           read_data_buffer,
                           buffer_size
                          );
