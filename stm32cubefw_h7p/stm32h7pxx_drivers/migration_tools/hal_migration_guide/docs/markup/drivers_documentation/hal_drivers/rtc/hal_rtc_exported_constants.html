HAL2 

#define RTC_FLAG_RECALPF

In HAL1, these defines are used by the __HAL_RTC_GET_FLAG(__HANDLE__, __FLAG__) macro.

HAL_RTC_ALARM_PollForEvent(hal_rtc_alarm_t alarm, uint32_t timeout_ms)

For the rest of the defines you can go to the LL layer and use these functions to get the desired flags:

HAL RTC Get Flag macros .

In HAL1, these defines are used by the __HAL_RTC_SSRU_CLEAR_FLAG(__HANDLE__, __FLAG__) __HAL_RTC_CLEAR_FLAG(__HANDLE__, __FLAG__) macro.

In HAL2 the defines and macros are removed,

For the rest of the defines you can go to the LL layer and use these functions to clear the desired flags:

Use HAL RTC SSRU Clear Flag Macro and HAL RTC Clear Flag macros instead.
