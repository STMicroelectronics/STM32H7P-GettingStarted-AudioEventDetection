HAL RCC Function services ¶

This subsection provides a set of functions allowing to control the activation or deactivation of MSI PLL-mode, LSE CSS, Low speed clock output and clock after wake-up from STOP mode.

Clock Security system management (LSECSS) ¶

Function Description ¶

The HAL_RCCEx_EnableLSECSS and HAL_RCCEx_DisableLSECSS functions are used to enable and disable the Low-Speed External Clock Security System (LSECSS).

HAL1

HAL2

Function name

void HAL_RCCEx_EnableLSECSS(void);

void HAL_RCC_LSE_EnableCSS(void);

Function name

void HAL_RCCEx_DisableLSECSS(void);

void HAL_RCC_LSE_DisableCSS(void);

Example Usage ¶

HAL1

HAL2 

HAL_RCCEx_EnableLSECSS();

HAL_RCCEx_DisableLSECSS();

HAL_RCC_LSE_EnableCSS();

HAL_RCC_LSE_DisableCSS();

Oscillator clock source configuration for wakeup from Stop and CSS backup clock ¶

Function Description ¶

The HAL_RCCEx_WakeUpStopCLKConfig and HAL_RCCEx_KerWakeUpStopCLKConfig functions are used to configure the clock settings after waking up from stop mode. In HAL2, these functions have been renamed, and two new functions have been added to retrieve the current configuration.

HAL1

HAL2

Function name

void HAL_RCCEx_WakeUpStopCLKConfig(uint32_t WakeUpClk);

void HAL_RCC_SetClockAfterWakeFromStop(hal_rcc_stop_wakeup_clk_t wakeup_clk);

Function name

void HAL_RCCEx_KerWakeUpStopCLKConfig(uint32_t WakeUpClk);

void HAL_RCC_SetKernelClkAfterWakeFromStop(hal_rcc_stop_wakeup_kerclk_t wakeup_clk);

New Function

N/A

hal_rcc_stop_wakeup_clk_t HAL_RCC_GetClockAfterWakeFromStop(void);

New Function

N/A

hal_rcc_stop_wakeup_kerclk_t HAL_RCC_GetKernelClkAfterWakeFromStop(void);

Example Usage ¶

HAL1

HAL2 

uint32_t wakeup_clk = RCC_WAKEUPSTOPCLK_MSI;
HAL_RCCEx_WakeUpStopCLKConfig(wakeup_clk);


uint32_t ker_wakeup_clk = RCC_WAKEUPSTOPCLK_MSI;
HAL_RCCEx_KerWakeUpStopCLKConfig(ker_wakeup_clk);

hal_rcc_stop_wakeup_clk_t wakeup_clk = HAL_RCC_STOP_WAKEUP_CLK_MSI;
HAL_RCC_SetClockAfterWakeFromStop(wakeup_clk);


hal_rcc_stop_wakeup_kerclk_t ker_wakeup_clk = HAL_RCC_STOP_WAKEUP_KERCLK_MSI;
HAL_RCC_SetKernelClkAfterWakeFromStop(ker_wakeup_clk);


wakeup_clk = HAL_RCC_GetClockAfterWakeFromStop();


ker_wakeup_clk = HAL_RCC_GetKernelClkAfterWakeFromStop();

RCC Clock Security System interrupt request ¶

Function Description ¶

The HAL_RCC_EnableCSS , HAL_RCC_CSSCallback , and HAL_RCC_NMI_IRQHandler functions are used to manage the Clock Security System (CSS) and Non-Maskable Interrupt (NMI) handling. In HAL2, the CSS-related functions have been renamed to focus specifically on the High-Speed External (HSE) clock.

HAL2

Function name

Function name

HAL2
