LL SYSTEM APIs listing for migration ¶

Important

The most significant change for the LL SYSTEM file is its restructuring into five separate files:

  • LL SYSTEM : Specific for GENERIC Driver

  • LL DBGMCU : Specific for DBGMCU Driver

  • LL SYSCFG/SBS : Specific for SYSCFG/SBS Driver

  • LL VREFBUF : Specific for VREFBUF Driver

  • LL FLASH : Specific for FLASH Driver

This restructuring enhances modularity and clarity, allowing for more focused and maintainable code management.
