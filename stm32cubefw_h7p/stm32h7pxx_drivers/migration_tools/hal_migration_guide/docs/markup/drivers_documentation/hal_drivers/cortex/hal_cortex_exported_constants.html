HAL CORTEX constants migration ¶

This section provides information about the HAL CORTEX constants migration .

Note

For the following CORTEX constants, which were previously defined using #define macros, have been converted to an enumerated type (enum). This change enhances type safety and makes the code more readable and maintainable.

For more details refer to the concept : Replace Finite Parameter Defines (Including PPP Instances) with Enum Types at HAL Levels

HAL CORTEX SYSTICK Clock source constants ¶

In HAL2, the multiple clock source defines are replaced by a simplified enum with only two options: internal or external clock source. You should map your previous clock source to one of these enum values as follows:

  • Use HAL_CORTEX_SYSTICK_CLKSOURCE_INTERNAL for clock sources like HCLK and SYSCLK .

  • Use HAL_CORTEX_SYSTICK_CLKSOURCE_EXTERNAL for clock sources such as HCLK_DIV8 , LSI , LSE , SYSCLK_DIV16 , and SYSCLK_DIV64 .

This mapping ensures compatibility with the new HAL2 clock source configuration.

HAL1

HAL2 

/* */

#define SYSTICK_CLKSOURCE_HCLK_DIV8
#define SYSTICK_CLKSOURCE_LSI
#define SYSTICK_CLKSOURCE_LSE
#define SYSTICK_CLKSOURCE_HCLK

typedef enum
{
  HAL_CORTEX_SYSTICK_CLKSOURCE_INTERNAL,
  HAL_CORTEX_SYSTICK_CLKSOURCE_EXTERNAL
} hal_cortex_systick_clk_src_t;
