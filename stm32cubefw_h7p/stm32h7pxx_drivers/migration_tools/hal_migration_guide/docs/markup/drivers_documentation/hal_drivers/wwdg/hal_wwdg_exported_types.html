WWDG Typedef Enumeration Migration ¶

HAL1

HAL2 

typedef enum
{
  HAL_WWDG_EWI_CB_ID,
  HAL_WWDG_MSPINIT_CB_ID
} HAL_WWDG_CallbackIDTypeDef;

Removed.

Note

The callback registration in HAL2 is handled by specific functions for each WWDG event. See HAL WWDG Callback Register Functions for more details. HAL_WWDG_MSPINIT_CB_ID is removed because the function HAL_WWDG_MspInit is removed.

WWDG Initialization Structure Changes ¶

In HAL2, the WWDG_InitTypeDef structure has been deleted. The prescaler, window, and counter values are now calculated using private functions.

HAL1

HAL2 

typedef struct
{
    uint32_t Prescaler;
    uint32_t Window;
    uint32_t Counter;
    uint32_t EWIMode
} WWDG_InitTypeDef;

Removed,
The values of prescaler, window, counter, and the early wakeup interrupt
mode are now calculated  and configured based on the input parameters of
the function  HAL_WWDG_Start().
