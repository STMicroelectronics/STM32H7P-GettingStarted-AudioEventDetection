HAL PKA io operation functions migration ¶

This section provides information about the HAL PKA function migration.

HAL PKA abort ¶

HAL1

HAL2 

HAL_PKA_Abort()

HAL_PKA_Abort()

Note

The execution of an operation is split into two main functions:

  • HAL_PKA_SetConfig$Operation$ to configure the mode and input parameters of the given operation.

  • HAL_PKA_Compute / HAL_PKA_Compute_IT to start the computation in polling or interrupt modes whatever the operation is.
