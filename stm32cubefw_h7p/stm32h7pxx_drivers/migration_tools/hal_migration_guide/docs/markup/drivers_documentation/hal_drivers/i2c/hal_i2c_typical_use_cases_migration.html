HAL I2C Typical use cases for migration ¶

HAL I2C communication in polling mode use case ¶

Note

The API for all modes of communication was renamed between HAL1 and HAL2.

HAL1

HAL2

Sequence diagram

Usage 

/* Add your init and cpnfig */
HAL_I2C_Init(&hi2c);
HAL_I2CEx_ConfigAnalogFilter(&hi2c,
                             I2C_ANALOGFILTER_ENABLE) ;
/* Start a I2C Process */
HAL_I2C_Master_Transmit(&hi2c,
                        DevAddress,
                        &pData,
                        Size,
                        Timeout);

HAL_I2C_Init(&hi2c, HAL_I2C1);
HAL_I2C_SetConfig(&hi2c, &i2c_config);
HAL_I2C_EnableAnalogFilter(&hi2c);
/* Start a I2C Process */
HAL_I2C_MASTER_Transmit(&hi2c,
                        device_addr,
                        &p_data,
                         size_byte,
                         timeout_ms);

HAL_I2C_SLAVE_Receive_DMA(&hi2cx, RxBuffer, NumData);

HAL_I2C_SLAVE_Transmit_DMA(&hi2cx, TxBuffer, NumData);
