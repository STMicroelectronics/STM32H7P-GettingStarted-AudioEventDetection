HAL SMBUS io operation functions migration ¶

This section provides information about the HAL SMBUS io operation functions migration.

Important

The main difference between HAL1 and HAL2 in all transmit and receive functions in interrupt mode is the way buffer size is specified. HAL1 uses Size for the number of data elements (u16), while HAL2 uses Size_byte to specify the buffer size in bytes, allowing more precise control.

HAL SMBUS master receives data with interrupt ¶

HAL1

HAL2 

HAL_SMBUS_Master_Transmit_IT(SMBUS_HandleTypeDef *hsmbus, uint16_t DevAddress,
                                      uint8_t *pData, uint16_t Size, uint32_t XferOptions);
HAL_SMBUS_Master_Receive_IT(SMBUS_HandleTypeDef *hsmbus, uint16_t DevAddress,
                                     uint8_t *pData, uint16_t Size, uint32_t XferOptions);

HAL_SMBUS_MASTER_SEQ_Transmit_IT(hal_smbus_handle_t *hsmbus, uint32_t device_addr, const void *p_data,
                                     uint32_t size_byte, hal_smbus_xfer_opt_t xfer_opt);
HAL_SMBUS_MASTER_SEQ_Receive_IT(hal_smbus_handle_t *hsmbus, uint32_t device_addr, void *p_data,
                                    uint32_t size_byte, hal_smbus_xfer_opt_t xfer_opt);

HAL SMBUS fast mode plus configuration ¶

HAL1

HAL2 

HAL_SMBUSEx_ConfigFastModePlus(SMBUS_HandleTypeDef *hsmbus, uint32_t FastModePlus);

Removed.
Split the function HAL_SMBUSEx_ConfigFastModePlus in unitary APIs to enable and disable the fast mode plus
and the configuration of pin managed by SYSCFG driver ``HAL_SYSCFG_EnableI2CFastModePlus`` and ``HAL_SYSCFG_DisableI2CFastModePlus`` ,
or by HAL SBS driver ``HAL_SBS_EnableFastModePlus()`` , ``HAL_SBS_DisableFastModePlus()``.

Related concept : Add unitary configuration APIs
