HAL GFXMMU configure the lookup table (LUT) ¶

HAL1

HAL2

In HAL1, the user must enter the first and the last visible pixel for each line using STM32CubeMX to generate the lookup table automatically. The LUT contains the LUTxlow and LUTxhigh values, referring by uint32_t Address .

In HAL2,The LUT (Look-Up Table) is implemented as a union type that combines the raw 32-bit register values (LUTxL and LUTxH) with detailed bitfield structures (lut_low and lut_high). This design provides dual access modes for the user:

  • Raw Access: Direct manipulation of the entire 32-bit register value, useful for efficient register programming.

  • Field Access: Fine-grained access to individual bitfields within the LUT registers, which enhances readability and significantly improves the debugging experience.

By leveraging this approach, the LUT type remains compact and efficient for low-level register operations while offering a more intuitive interface for developers working with specific LUT parameters.

Note

The values in the LUT tables generated by STM32CubeMX are compatible with the HAL2 drivers when accessed through the raw row values.

HAL2 

HAL_StatusTypeDef HAL_GFXMMU_ModifyAddressCache(GFXMMU_HandleTypeDef *hgfxmmu,
                                                GFXMMU_AddressCacheTypeDef *AddressCache);

hal_status_t HAL_GFXMMU_DisableCache(hal_gfxmmu_handle_t *hgfxmmu);

Usage example: 

GFXMMU_AddressCacheTypeDef AddressCache;
/* Enable address cache */
AddressCache.Activation             = ENABLE;
AddressCache.AddressCacheLockBuffer = GFXMMU_ADDRESSCACHE_LOCK_BUFFER3;
HAL_GFXMMU_ModifyAddressCache(&GfxmmuHandle, &AddressCache);
 /* Disable address cache */
AddressCache.Activation             = DISABLE;
HAL_GFXMMU_ModifyAddressCache(&GfxmmuHandle, &AddressCache);

Usage example: 

/* Enable address cache */
HAL_GFXMMU_EnableCache(&hgfxmmu);
HAL_GFXMMU_EnableCacheLockBuff(&hgfxmmu, HAL_GFXMMU_BUFF_3);

/* Disable address cache */
HAL_GFXMMU_DisableCache(&hgfxmmu)
HAL_GFXMMU_DisableCacheLockBuff(&hgfxmmu);
