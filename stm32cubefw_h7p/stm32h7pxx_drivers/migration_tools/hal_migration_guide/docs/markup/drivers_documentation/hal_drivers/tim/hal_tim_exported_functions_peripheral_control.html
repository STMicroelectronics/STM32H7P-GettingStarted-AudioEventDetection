HAL TIM control functions migration ¶

This section provides information about the HAL TIM control functions migration.

HAL TIM Base Init function ¶

HAL1

HAL2

Initialization mode

  • In HAL1 to Initialize and to configure the TIM base you need to call:

    • HAL_TIM_Base_Init(&htim) .

  • In HAL2 just replace it with the following sequence:

    • HAL_TIM_Init(&htim, HAL_TIMi) to link between the handle and the instance.

    • HAL_TIM_SetConfig(&htim, &p_config) to set the basic time base configuration.

HAL TIM get active channel function ¶

HAL_TIM_GetActiveChannel function is used to determine which channel of a timer is currently active. This function is particularly useful in interrupt service routines (ISRs) or callback functions where you need to handle different timer channels distinctly.

Function

HAL1

HAL2

HAL_TIM_GetActiveChannel

Removed because the channel is added as an argument for each callback function which depends on the channel.

Example

HAL_TIM_IC_CaptureCallback(TIM_HandleTypeDef *htim);

HAL_TIM_InputCaptureCallback(hal_tim_handle_t *htim, hal_tim_channel_t channel);

HAL TIM Commutation event functions ¶

HAL1

HAL2

Polling mode

  • In HAL1 to configure the TIM commutation event sequence in polling mode you need to call:

    • HAL_TIMEx_ConfigCommutEvent .

  • In HAL2 just replaced by the following sequence:

    • HAL_TIM_EnableCommutation

    • HAL_TIM_Start

Interrupt mode

  • In HAL1 to configure the TIM commutation event sequence in interrupt mode you need to call:

    • HAL_TIMEx_ConfigCommutEvent_IT .

  • In HAL2 just replaced by the following sequence:

    • HAL_TIM_EnableCommutation

    • HAL_TIM_Start_IT

DMA mode

  • In HAL1 to configure the TIM commutation event sequence in DMA mode you need to call:

    • HAL_TIMEx_ConfigCommutEvent_DMA .

  • In HAL2 just replaced by the following sequence:

    • HAL_TIM_EnableCommutation

    • HAL_TIM_Start_DMA

Note

In HAL1, the function HAL_TIMEx_ConfigCommutEvent/IT/DMA(TIM_HandleTypeDef *htim, uint32_t InputTrigger, uint32_t CommutationSource) requires three arguments. When the CommutationSource is set to TIM_COMMUTATION_SOFTWARE , the InputTrigger must be TIM_TS_NONE . In HAL2, the implementation changes to HAL_TIM_EnableCommutation , which no longer requires specifying the InputTrigger for any selected commutation_source . Consequently, TIM_TS_NONE is removed from HAL2..

HAL TIM TI1 Input Configuration ¶

HAL1

HAL2

TI1 Input Configuration

  • In HAL1, the TI1 input configuration is handled by the following function:

    • HAL_TIM_ConfigTI1Input This function is used to select the signal connected to the TI1 input: direct from CH1_input or a XOR combination between CH1_input, CH2_input & CH3_input.

  • In HAL2, the TI1 input configuration is handled by the following functions:

    • HAL_TIM_IC_EnableXORGate This function enables the XOR gate between CH1_input, CH2_input & CH3_input.

    • HAL_TIM_IC_DisableXORGate This function disables the XOR gate and directly connects TI1 input from CH1_input.

HAL TIM OCREF Clear Configuration ¶

HAL1

HAL2

OCREF Clear Configuration

  • In HAL1, the OCREF clear configuration is handled by the following function:

    • HAL_TIM_ConfigOCrefClear

  • In HAL2, the OCREF clear configuration is handled based on the source:

    • If ETR is used as the OCREF source:

      • HAL_TIM_SetExternalTriggerInput

      • HAL_TIM_SetOCRefClearSource

      • HAL_TIM_EnableChannelOCRefClear

    • Else:

      • HAL_TIM_SetOCRefClearSource

      • HAL_TIM_EnableChannelOCRefClear

HAL TIM Slave Configuration Functions ¶

HAL1

HAL2

Blocking Mode

  • In HAL1, to configure the TIM in Slave mode we need to call:

    • HAL_TIM_SlaveConfigSynchro

  • In HAL2, it is handled by:

    • HAL_TIM_SetSynchroSlave : to select the slave mode and the input trigger.

    • Then according to the input trigger selected, call the appropriate function:

      • If Internal Trigger ITRx is selected, there is no configuration to do.

      • If ETRF is selected, the function HAL_TIM_SetExternalTriggerInput is called.

      • If the trigger is TI1F_ED , TI1FP1 or TI2FP2 , the functions HAL_TIM_IC_SetConfigChannel and HAL_TIM_IC_SetConfigCaptureUnit are called.

    • Finally to start in blocking mode: HAL_TIM_Start

Interrupt Mode

  • In HAL1, it is handled by the following functions:

    • To configure: HAL_TIM_SlaveConfigSynchro_IT

  • In HAL2, it is handled by:

    • HAL_TIM_SetSynchroSlave : to select the slave mode and the input trigger.

    • Then according to the input trigger selected, call the appropriate function:

      • If Internal Trigger ITRx is selected, there is no configuration to do.

      • If ETRF is selected, the function HAL_TIM_SetExternalTriggerInput is called.

      • If the trigger is TI1F_ED , TI1FP1 or TI2FP2 , the functions HAL_TIM_IC_SetConfigChannel and HAL_TIM_IC_SetConfigCaptureUnit are called.

    • Finally to start in interrupt mode: HAL_TIM_Start_IT

HAL TIMEx Enable HSE32 Functions ¶

HAL1

HAL2

Configuration

  • In HAL1 to enable HSE32 you need to call:

    • HAL_TIMEx_EnableHSE32 .

  • In HAL2 it is removed and to get the functionality you need to call the function:

    • HAL_TIM_IC_SetConfigChannel

    And to select the source from the structure hal_tim_ic_channel_config_t :

    • HAL_TIM_INPUT_TIM17_TI1_HSE_DIV32 or HAL_TIM_INPUT_TIM16_TI1_HSE_DIV32 according to the timer selected at the beginning.

Note

to disable HSE32 you need to select onther input source.

HAL TIMEx Config Break Dead Time Functions ¶

HAL1

HAL2

Configuration

  • In HAL1 the configuration of the Break feature, dead time, Lock level, OSSI/OSSR State, and the AOE (automatic output enable) is done with one function:

    • HAL_TIMEx_ConfigBreakDeadTime .

  • In HAL2 this function is split into multiple functions where each function handles a specific functionality:

    • HAL_TIM_BREAK_SetConfigInput

    • HAL_TIM_BREAK_EnableInput

    • HAL_TIM_SetDeadtime

    • HAL_TIM_BREAK_SetOutputOffStates

    • HAL_TIM_SetLockLevel

    • HAL_TIM_BREAK_EnableAutomaticOutput

HAL1

HAL2

Initialization mode

  • In HAL1 to configure the Break input source you need to call:

    • HAL_TIMEx_ConfigBreakInput .

  • In HAL2 this function is split into multiple functions where each function handles a specific functionality:

    • HAL_TIM_BREAK_EnableInputSource :to enable the input source selected.

    • HAL_TIM_BREAK_SetInputSourcePolarity :to set the polarity.

HAL TIMEx Config Dead Time Functions ¶

HAL1

HAL2

  • In HAL1 to configure the dead time you need to call:
