Purpose

STM32Cube is an STMicroelectronics original initiative to ease developers life by reducing development efforts, time and cost.

STM32Cube covers STM32 portfolio.

STM32Cube includes:

  • A comprehensive embedded software platform, delivered per series (such as STM32CubeH7P for STM32H7P series)

    • The STM32Cube HAL, an STM32 abstraction layer embedded software, ensuring maximized portability across STM32 portfolio

    • A consistent set of middleware libraries such as FreeRTOS.

    • A full set of examples for each board provided for this STM32 series.

The STM32Cube firmware solution offers a straightforward API with a modular architecture, making it simple to fine tune custom applications and scalable to fit most requirements.

Both the HAL and LL drivers have been developed in compliance with V Model requirements for design, implementation, and tests. Furthermore, the STMicroelectronics-specific validation process adds a deeper qualification level, such as compliance with MISRA C®:2012 guidelines, elimination of possible runtime errors with the Synopsys® Coverity® static analysis tool, and code coverage by running tests on STM32 hardware with the LDRA® dynamic analysis tool. Reports are available on demand.

The drivers provided within this package support the STM32H7P lines.

Update history

2nd Alpha release

2nd release of STM32Cube SW Package for STM32H7P Series, supporting STM32H7P5Ixx devices.


Main changes

  • The release includes HAL Drivers, DFP, Utilities and template on STM32H7P board.
  • It focuses on HAL Drivers. HAL evolutions bring in footprint and performance optimizations, as well as new APIs proposed to improve developer’s experience.


Contents

CMSIS Drivers

  • Official CMSIS core from ARM.

Device Family Pack (DFP)

  • CMSIS Device (headers, startups).
  • Device Support (FlashLoaders, SVD, linker templates).
  • Please refer to the DFP release notes for details.

HAL/LL Drivers

  • HAL/LL Drivers are available for all peripherals:
    • System Core : CORTEX, CRS, DBGMCU, DMA, EXTI, FLASH, GPIO, IWDG, PWR, Q, RAMECC, RCC, SBS, TAMP, WWDG
    • Analog : ADC, ADF, COMP, DAC, DTS, VREFBUF
    • Timers : RTC, TIM, HRTIM
    • Connectivity : FDCAN, I2C, I3C, SMARTCARD, SMBUS, I2S, SPI, UART, LPUART, USART
    • Security : CRC, HASH, RNG
    • Memory : MMC, SD, SDIO, SRAM, XSPI
    • Computing : CORDIC, CRC, FMAC, HSP
    • Core MW : OSAL, USB (HCD, PCD, Core), UCPD
    • HAL/LL Drivers update based on Silicon validation
    • Please refer STM32CubeH7P HAL and LL drivers release notes for details on HAL.

Utilities

  • syscall: implements the operating system interface documented by newlib.

Examples

  • Examples demonstrating features on NUCLEO-H7P5I board.
  • Project extractor allows users to select one example for one board and one IDE, and extract it to a standalone self-contained directory.
  • The examples are delivered in a preliminary format with support of IAR EWARM only.
  • PRINTF is disabled by default in most of the examples and can be activated.
  • Open-CMSIS with AC6 toolchain projects available.
  • One MDK-ARM Keil µVision template project available.

Known limitations

  • Being an Alpha release, drivers are delivered with alpha maturity and partial coverage for some of them.
    • Drivers validation is not completed.
    • Drivers for FMC are not available.
  • Configuration and Code Generation is not supported
  • All examples projects are generated with IAR EWARM IDE only.
  • IAR EWARM IDE can have some issues with too long paths. For proper operation, project extractor should be used.


Development toolchains and compilers

  • IAR Embedded Workbench for ARM (EWARM) toolchain V9.60.3 + ST-LINK, patch available here: EWARMv9_STM32H7Pxx
  • MDK-ARM Keil µVision V5.42.

Supported devices and boards

  • All STM32H7Pxx devices are supported.
