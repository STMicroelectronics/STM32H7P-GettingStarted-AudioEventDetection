HAL RTC macros migration ¶

This section provides information about the HAL RTC macros migration .

HAL RTC Reset Handle State macros ¶

HAL1

HAL2 

#define __HAL_RTC_RESET_HANDLE_STATE()

Handle is removed in HAL2.

HAL RTC Write Protection Disable macros ¶

HAL1

HAL2 

#define __HAL_RTC_WRITEPROTECTION_DISABLE()

HAL_RTC_DisableWriteProtection(void)

HAL RTC Write Protection Enable macros ¶

HAL1

HAL2

HAL_RTC_EnableWriteProtection(void)

HAL RTC ALARM A/B Enable macros ¶

HAL1

HAL2 

#define __HAL_RTC_ALARMA_ENABLE()
#define __HAL_RTC_ALARMB_ENABLE()

In HAL2 the alarm activation management is handled by:

HAL_RTC_ALARM_Start(hal_rtc_alarm_t alarm, uint32_t interruption)

If needed, you can enable each alarm separately with:

LL_RTC_ALMA_Enable()

LL_RTC_ALMB_Enable()
