HAL ADC constants migration ¶

This section provides information about the HAL ADC constants migration .

HAL ADC state constants ¶

HAL1

HAL2 

#define HAL_ADC_STATE_RESET     (0x00000000UL)
#define HAL_ADC_STATE_READY     (0x00000001UL)
#define HAL_ADC_STATE_REG_BUSY  (0x00000100UL)
#define HAL_ADC_STATE_AWD1     (0x00010000UL)

typedef enum {
    HAL_ADC_STATE_RESET,
    HAL_ADC_STATE_INIT,
    HAL_ADC_STATE_CONFIGURING,
    HAL_ADC_STATE_IDLE,
    HAL_ADC_STATE_ACTIVE,
    HAL_ADC_STATE_CALIB,
} hal_adc_state_t;

typedef enum {
    HAL_ADC_GROUP_STATE_RESET,
    HAL_ADC_GROUP_STATE_IDLE,
    HAL_ADC_GROUP_STATE_ACTIVE,
    HAL_ADC_GROUP_STATE_ACTIVE_SILENT,
} hal_adc_group_state_t;

typedef enum {
    HAL_ADC_COMMON_STATE_RESET,
    HAL_ADC_COMMON_STATE_INDEPT,
    HAL_ADC_COMMON_STATE_LINKED,
    HAL_ADC_COMMON_STATE_MM,
} hal_adc_common_state_t;

Summary of key changes

  1. Conversion of constants to enumeration types:

    • Bitfield macros have been replaced with type-safe enumeration types.

  2. Refactoring of the state machine:

    • A single global state machine has been split into three distinct state machines:

      1. Global state: hal_adc_state_t

      2. Group state: hal_adc_group_state_t

      3. Common state: hal_adc_common_state_t

Related concepts: Revise and optimize the HAL state machine.
