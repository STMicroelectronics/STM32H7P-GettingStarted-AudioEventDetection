HAL GFXMMU cache lock buffer/address cache lock buffer indices constants ¶

HAL1

HAL2

  • In HAL1, the cache lock buffer is a member of the GFXMMU_CachePrefetchTypeDef structure. 

#define GFXMMU_CACHE_LOCK_BUFFER0
#define GFXMMU_CACHE_LOCK_BUFFER1
#define GFXMMU_CACHE_LOCK_BUFFER2
#define GFXMMU_CACHE_LOCK_BUFFER3

  • In HAL1, the address cache lock buffer is a member of the GFXMMU_AddressCacheTypeDef structure. 

#define GFXMMU_ADDRESSCACHE_LOCK_BUFFER0
#define GFXMMU_ADDRESSCACHE_LOCK_BUFFER1
#define GFXMMU_ADDRESSCACHE_LOCK_BUFFER2
#define GFXMMU_ADDRESSCACHE_LOCK_BUFFER3

These constants are removed from HAL2, the cache lock buffer/address cache lock buffer are managed by unitary functions in the HAL layer. 

hal_status_t HAL_GFXMMU_EnableCacheLockBuff(hal_gfxmmu_handle_t *hgfxmmu,
                                            hal_gfxmmu_buff_t buff);

hal_status_t HAL_GFXMMU_DisableCacheLockBuff(hal_gfxmmu_handle_t *hgfxmmu);

hal_gfxmmu_buff_t is to choose the buffer index.

For more details, refer to HAL GFXMMU cache and prefetch structure type definition and HAL GFXMMU address cache structure type definition .

HAL GFXMMU cache force operations constants ¶

HAL1

HAL2

In HAL1, the cache force is a member of the GFXMMU_CachePrefetchTypeDef structure. 

#define GFXMMU_CACHE_FORCE_DISABLE
#define GFXMMU_CACHE_FORCE_ENABLE

These constants are removed from HAL2, the cache force is managed by unitary functions in the HAL layer. 

hal_status_t HAL_GFXMMU_DisableForceCache(hal_gfxmmu_handle_t *hgfxmmu);
hal_status_t HAL_GFXMMU_EnableForceCache(hal_gfxmmu_handle_t *hgfxmmu);

/* */


#define GFXMMU_CACHE_FORCE_FLUSH
#define GFXMMU_CACHE_FORCE_INVALIDATE

These constants are removed from HAL2, the cache flush and/or invalidate is managed by unitary functions in the HAL layer. 

hal_status_t HAL_GFXMMU_CleanCache(hal_gfxmmu_handle_t *hgfxmmu);
hal_status_t HAL_GFXMMU_InvalidateCache(hal_gfxmmu_handle_t *hgfxmmu);
hal_status_t HAL_GFXMMU_CleanInvalidateCache(hal_gfxmmu_handle_t *hgfxmmu);

HAL GFXMMU lut line enable/disable constants ¶

HAL1

HAL2

In HAL1, the lut line status is member for GFXMMU_LutLineTypeDef structure. 

#define GFXMMU_LUT_LINE_DISABLE
#define GFXMMU_LUT_LINE_ENABLE

These constants are removed from HAL2, the lut line status is no more available and the equivalent is automatically enabled by setting the LUT lines structure hal_gfxmmu_lut_t . You can use HAL_GFXMMU_SetLUT() function to enable and set a LUT configuration and use HAL_GFXMMU_ResetLutLines() to disable the LUT configuration.
