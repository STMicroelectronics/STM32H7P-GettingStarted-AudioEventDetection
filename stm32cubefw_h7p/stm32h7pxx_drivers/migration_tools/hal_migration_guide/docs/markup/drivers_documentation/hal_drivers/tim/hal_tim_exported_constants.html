HAL TIM constants migration ¶

This section provides information about the HAL TIM constants migration.

HAL TIM Constants replaced by enumeration ¶

HAL TIM Output Compare Clear (OCREFCLR) Source ¶

HAL1

HAL2 

/*  */

#define TIM_CLEARINPUTSOURCE_OCREFCLR



#define TIM_CLEARINPUTSOURCE_ETR

             .

Important

In HAL2, the OCREFCLR source is transitioned to an enumeration type, hal_tim_ocrefclear_src_t. The TIM_CLEARINPUTSOURCE_NONE no more used and a new programming sequence using the OCREF or the ETR is provided.

HAL TIM Constants replaced by LL TIM constants ¶

Note

Some HAL constants are being replaced with LL constants.

Related concepts: HAL defines and enum(those used for HW registers) are redirected to the equivalent LL ones.

For example, the following changes are being made:

HAL TIM OUTPUTSTATE ¶

HAL1

HAL2

#define TIM_OUTPUTSTATE_ENABLE

Removed and replaced by LL constants LL_TIM_OCSTATE_DISABLE

#define TIM_OUTPUTSTATE_DISABLE

Removed and replaced by LL constants LL_TIM_OCSTATE_ENABLE

Note

TIM_OUTPUTNSTATE_DISABLE and TIM_OUTPUTNSTATE_ENABLE are also removed. To configure it, you need to choose also LL_TIM_OCSTATE_ENABLE or LL_TIM_OCSTATE_DISABLE and just you need to specify the complementary channel.
