HAL UART macros migration ¶

This section provides information about the HAL UART macros migration .

Note

The following UART macros have been transitioned to inline functions, enhancing efficiency and type safety.

Related concept : All public macros related to hardware (HW) are removed, and equivalent services added to the LL layer.

HAL UART enable/disable ¶

HAL1

HAL2 

#define __HAL_USART_ENABLE(__HANDLE__)
#define __HAL_USART_DISABLE(__HANDLE__)

__STATIC_INLINE void LL_USART_Enable(USART_TypeDef *p_usart)
__STATIC_INLINE void LL_USART_Disable(USART_TypeDef *p_usart)

HAL UART get flag/interrupt ¶

HAL1

HAL2 

#define __HAL_UART_GET_IT(__HANDLE__, __INTERRUPT__)
/*OR*/
#define __HAL_UART_GET_FLAG(__HANDLE__, __FLAG__)

HAL UART hardware control ¶

HAL1

HAL2 

/* */

 #define __HAL_UART_HWCONTROL_CTS_ENABLE(__HANDLE__)

 #define __HAL_UART_HWCONTROL_RTS_ENABLE(__HANDLE__)


 #define __HAL_UART_HWCONTROL_CTS_DISABLE(__HANDLE__)
 #define __HAL_UART_HWCONTROL_RTS_DISABLE(__HANDLE__)
In HAL2, use the function HAL_UART_SetHwFlowCtl() to manage RTS and CTS:

  • Enable RTS : Pass HAL_UART_HW_CONTROL_RTS as the parameter.

  • Enable CTS : Pass HAL_UART_HW_CONTROL_CTS as the parameter.

  • Enable both RTS and CTS : Pass HAL_UART_HW_CONTROL_RTS_CTS .

  • Disable hardware control : Pass HAL_UART_HW_CONTROL_NONE . 

HAL_UART_SetHwFlowCtl(const hal_uart_handle_t *huart,
                      hal_uart_hw_control_t hw_flow_ctl)
