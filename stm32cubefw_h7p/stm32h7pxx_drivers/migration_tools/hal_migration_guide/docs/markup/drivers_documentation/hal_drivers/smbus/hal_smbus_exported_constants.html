HAL SMBUS state code constants ¶

HAL1

HAL2

In HAL1, SMBUS state implementation using defines represent bit flag that can be combined using the bitwise OR operator (|) allowing multiple simultaneous states by combining flags for example state = HAL_SMBUS_STATE_MASTER_BUSY_TX | HAL_SMBUS_STATE_LISTEN .

In HAL2, each possible combination of states is explicitly defined as unique enumerator. 

/**/

#define HAL_SMBUS_STATE_RESET
#define HAL_SMBUS_STATE_MASTER_BUSY_TX
#define HAL_SMBUS_STATE_MASTER_BUSY_RX
#define HAL_SMBUS_STATE_LISTEN
#define HAL_SMBUS_STATE_SLAVE_BUSY_TX
#define HAL_SMBUS_STATE_SLAVE_BUSY_RX
#define HAL_SMBUS_STATE_BUSY
#define HAL_SMBUS_STATE_READY

typedef enum
{
  HAL_SMBUS_STATE_RESET
  HAL_SMBUS_STATE_INIT
  HAL_SMBUS_STATE_IDLE
  HAL_SMBUS_STATE_TX
  HAL_SMBUS_STATE_RX
  HAL_SMBUS_STATE_LISTEN
  HAL_SMBUS_STATE_TX_LISTEN
  HAL_SMBUS_STATE_RX_LISTEN

} hal_smbus_state_t;

HAL2

Removed: The choice between 7-bit and 10-bit addressing, as possible in the I2C protocol, is not relevant in SMBus protocol.
the SMBus restricts itself to 7-bit addressing with reserved address ranges for certain uses, which simplifies and
standardizes communication between devices.

SMBUS fast mode plus I2C peripherals constants ¶

HAL1

HAL2

In HAL1 the SMBUS enable fast mode plus and disable are managed by APIs void HAL_SMBUSEx_EnableFastModePlus() , void HAL_SMBUSEx_DisableFastModePlus()

The parameter ConfigFastModePlus selects the pin and can be one of these defines.

In HAL2 the SMBUS enable fast mode plus and disable are managed by APIs HAL_SMBUS_EnableFastModePlus() , HAL_SMBUS_DisableFastModePlus() and the selection of pin is managed by

SYSCFG driver void HAL_SYSCFG_EnableI2CFastModePlus() , void HAL_SYSCFG_DisableI2CFastModePlus() or SBS driver HAL_SBS_EnableFastModePlus() , HAL_SBS_DisableFastModePlus() . The parameter fast_mode_plus can be one of these HAL defines.

#define SMBUS_FASTMODEPLUS_I2C1
#define SMBUS_FASTMODEPLUS_I2C2
#define SMBUS_FASTMODEPLUS_I2C3
#define SMBUS_FASTMODEPLUS_I2C4
