HAL QSPI constants migration ¶

This section provides information about the HAL QSPI constants migration .

Note

All constants are migrated using the following concepts:

  • Replace Finite Parameter Defines (Including PPP Instances) with Enum Types at HAL Levels.

  • Add HAL_PPP Prefix to All HAL Peripheral APIs (Defines, Macros, Types, and Functions).

HAL QSPI chip select high time ¶

HAL1

HAL2 

#define QSPI_CS_HIGH_TIME_1_CYCLE
#define QSPI_CS_HIGH_TIME_2_CYCLE
#define QSPI_CS_HIGH_TIME_3_CYCLE
#define QSPI_CS_HIGH_TIME_4_CYCLE
#define QSPI_CS_HIGH_TIME_5_CYCLE
#define QSPI_CS_HIGH_TIME_6_CYCLE
#define QSPI_CS_HIGH_TIME_7_CYCLE
#define QSPI_CS_HIGH_TIME_8_CYCLE

Those defines have been removed from HAL2 and are now replaced by the cs_high_time_cycle parameter inside the hal_xspi_timing_config_t structure, which can take a value between 1 and 64.
