SYSCFG Get Flag ¶

HAL1

HAL2

Example 

#define SYSCFG_FLAG_SRAM2_PE
#define SYSCFG_FLAG_SRAM2_BUSY
#define SYSCFG_FLAG_SRAM_PE
#define SYSCFG_FLAG_CCMSRAM_BUSY
                 .
                 .
                 .

In HAL1, these defines are used by the macro __HAL_SYSCFG_GET_FLAG(__FLAG__) to retrieve the flag status.

In HAL2, the HAL flag defines and macros have been removed. Instead, use HAL_SYSCFG_IsActiveFlag() with the appropriate parameters.

For more details, refer to Flags Management .

Note

The availability and behavior of these flags may vary between different STM32 series.

Memories Erase Flags Status ¶

HAL1

HAL2

Example SBS 

#define SBS_MEMORIES_ERASE_FLAG_MCLR
#define SBS_MEMORIES_ERASE_FLAG_IPMEE

In HAL1, these defines are used by the macros __HAL_SBS_GET_MEMORIES_ERASE_STATUS(__FLAG__)

or __HAL_SBS_CLEAR_MEMORIES_ERASE_STATUS(__FLAG__) to manage the status of memory erase flags.

In HAL2, the HAL flag defines and macros have been removed.

Instead, use the static inline functions declared in the LL layer to manage memory erase status.

For more details, refer to Check and Clear SBS Memories Erase Status Flags .

Note

The availability and behavior of these flags may vary between different STM32 series.

HAL2
