HAL OSPI constants migration ¶

This section provides information about the HAL OSPI constants migration .

Note

All constants are migrated using the following concept: Replace Finite Parameter Defines (Including PPP Instances) with Enum Types at HAL Levels.

HAL OSPI IO manager IO port ¶

There are only two available ports, HAL_XSPIM_IOPORT_3 to HAL_XSPIM_IOPORT_8 are not physically present. They were removed in HAL2.

For more details refer to : HAL OSPI IO manager configuration
