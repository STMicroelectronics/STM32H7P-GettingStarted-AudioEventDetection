HAL I2C dual addressing mode constants ¶

HAL1

HAL2

In HAL1, the I2C dual addressing mode is a member of the I2C_InitTypeDef structure.

Removed: In HAL2, the I2C dual addressing mode is managed by unitary functions in the HAL layer.

For more details, refer to HAL I2C configuration structure . 

#define I2C_DUALADDRESS_DISABLE
#define I2C_DUALADDRESS_ENABLE

HAL I2C fast mode plus constants ¶

HAL1

HAL2

  • In HAL1 the I2C enable fast mode plus and disable are managed by APIs void HAL_I2CEx_EnableFastModePlus(uint32_t ConfigFastModePlus) , void HAL_I2CEx_DisableFastModePlus(uint32_t ConfigFastModePlus)

  • The parameter ConfigFastModePlus Selects the pin and can be one this defines.

  • In HAL2 the I2C enable fast mode plus and disable are managed by APIs HAL_I2C_EnableFastModePlus() , HAL_I2C_DisableFastModePlus() and the selection of pin is managed by void HAL_SYSCFG_EnableI2CFastModePlus(uint32_t fast_mode_plus) .

  • The parameter fast_mode_plus can be one of this HAL defines.
