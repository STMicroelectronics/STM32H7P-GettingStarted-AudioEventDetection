Related concepts :

  • Replace Finite Parameter Defines (Including PPP Instances) with Enum Types at HAL Levels.

  • Add HAL_PPP Prefix to All HAL Peripheral APIs (Defines, Macros, Types, and Functions).

Note

According to the concept All public macros related to hardware (HW) are removed, and equivalent services added to the LL layer. , the defines and macros used to set, clear, enable, or disable interrupts and flags have been removed. Instead, use the LL APIs. In the case of HAL I2S, the LL SPI interface is used to implement the I2S protocol.

HAL I2S master keep IO state constants ¶

HAL1

HAL2

In HAL1, the I2S master keep IO state is a member of the I2S_InitTypeDef structure.

Removed: In HAL2, the I2S master keep io state is managed by unitary functions in the HAL layer.

For more details, refer to HAL I2S initialization structure . 

#define I2S_MASTER_KEEP_IO_STATE_DISABLE
#define I2S_MASTER_KEEP_IO_STATE_ENABLE

hal_status_t HAL_I2S_DisableMasterKeepIOState(hal_i2s_handle_t *hi2s);
hal_status_t HAL_I2S_EnableMasterKeepIOState(hal_i2s_handle_t *hi2s);
