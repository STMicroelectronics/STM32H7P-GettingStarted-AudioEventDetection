HAL SRAM Typical use cases for migration ¶

This section provides information about the HAL SRAM Typical use cases for migration.

Note

HAL2, HAL SRAM do only the FMC configuration to access the external memory, No more processing (Read/Write) APIs anymore. Once the FMC is configured, SRAM become memory mapping and accessible for CPU and other master. To checkout the different cases of configuration and how to use them see HAL SRAM initialization and configuration functions migration .

Read and write operations ¶

HAL1

HAL2 

/* - */



// Write data to the SRAM memory
HAL_SRAM_Write_8b(&hsram,
                   (uint32_t *)(target_address),
                   data_to_write,
                   BufferSize
                  );

// Read data from the SRAM memory
HAL_SRAM_Read_8b(&hsram,
                  (uint32_t *)(target_address),
                  data_read,
                  BufferSize
                 );

uint32_t size;
uint8_t *psramaddress = (uint8_t *)target_address;
uint8_t *psrcbuff = data_to_write;
uint8_t *pdestbuff = data_read;
/* Write data to memory */
for (size = BufferSize; size != 0U; size--)
{
   *psramaddress = *psrcbuff;
   psrcbuff++;
   psramaddress++;
}
/* Read data from memory */
for (size = BufferSize; size != 0U; size--)
{
   *pdestbuff = *psramaddress;
   pdestbuff++;
   psramaddress++;
}

                           BufferSize
                          );

/* Read data from memory */

                           (uint32_t *)(target_address),
                           data_read,
                           BufferSize
                          );

Disable unused memory ¶

Note

When the external SRAM is not needed , it is possible to disable the HAL SRAM (to save Power).

HAL1

HAL2

The only option to disable the SRAM is to deinitialize the HAL SRAM driver. When the SRAM is needed again, the user must perform the initialization sequence once more.

It is possible to simply disable the HAL SRAM without full deinitialization when the SRAM is no longer needed, and to re-enable it once the external memory is required again . 

/* Perform any access operation */

/* Deinitialize the SRAM */
HAL_SRAM_DeInit(&hsram);
/* Reinitialize the SRAM */
HAL_SRAM_Init(&hsram, &Sram_Timing, NULL);

/* Perform any access operation */

/* Perform any access operation */

/* Disable an SRAM sub-bank to save power */
HAL_SRAM_DisableMemory(&hsram);
/* Enable the corresponding SRAM sub-bank */
HAL_SRAM_EnableMemory(&hsram);

/* Perform any access operation */

Disable and enable write protection ¶

Note

The API HAL SRAM write operation disable have been renamed to write protection enable .

HAL1

HAL2 

/* Enable write operation */
HAL_SRAM_WriteOperation_Enable(&hsram);

/* Do some write operations if needed */

/* Disable write operation */
HAL_SRAM_WriteOperation_Disable(&hsram);

/* Disable the Write protection */
HAL_SRAM_DisableWriteProtection(&hsram);

/* Do some write operations if needed */

/* Enable the Write protection */
HAL_SRAM_EnableWriteProtection(&hsram);
