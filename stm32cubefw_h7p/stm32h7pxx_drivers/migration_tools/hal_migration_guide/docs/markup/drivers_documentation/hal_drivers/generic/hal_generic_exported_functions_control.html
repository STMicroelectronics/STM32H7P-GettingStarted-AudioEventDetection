This section provides information about the HAL GENERIC control functions migration.

HAL_InitTick Migration ¶

In HAL2, the HAL_InitTick function has been updated to include the functionality of HAL_SetTickFreq , consolidating both functions into a single one.

HAL1

HAL2

Function name 

HAL_StatusTypeDef HAL_SetTickFreq(HAL_TickFreqTypeDef Freq);
HAL_StatusTypeDef HAL_InitTick(uint32_t TickPriority);

hal_status_t HAL_InitTick(hal_tick_freq_t tick_freq,
                          uint32_t tick_priority);

Parameters 

HAL_InitTick:
uint32_t TickPriority

HAL_SetTickFreq:
HAL_TickFreqTypeDef Freq

hal_tick_freq_t tick_freq
uint32_t tick_priority

HAL_MspInit and HAL_MspDeInit ¶

HAL1

HAL2

Function names 

void HAL_MspInit(void);
void HAL_MspDeInit(void);

In HAL2, these functions have been removed. Users are required to implement their own sequences for initialization and deinitialization.

Get Device ID ¶

HAL1

HAL2

Description

In HAL1, the function to get the device ID is named HAL_GetDEVID and returns a uint32_t .

In HAL2, it has been moved to the DBGMCU driver, renamed to HAL_DBGMCU_GetDeviceID , and the return type has been changed to hal_dbgmcu_device_id_t .

Function name 

uint32_t HAL_GetDEVID(void)

hal_dbgmcu_device_id_t HAL_DBGMCU_GetDeviceID(void)

Enable/Disable IO Analog Switch Booster ¶

HAL1

HAL2

Description

In HAL1, there are separate functions to enable and disable the IO analog switch booster. Additionally, in HAL1, there are separate functions to enable and disable the IO analog voltage selection.

In HAL2, these functionalities have been merged into a single function with a parameter. To enable the booster, use HAL_SYSCFG_BOOSTER_SUPPLY as the parameter; to disable it, use HAL_SYSCFG_VDDA_SUPPLY . To enable the voltage selection, use HAL_SYSCFG_VDD_SUPPLY as the parameter.

Function name 

void HAL_SYSCFG_EnableIOAnalogSwitchBooster(void);
void HAL_SYSCFG_DisableIOAnalogSwitchBooster(void);
void HAL_SYSCFG_EnableIOAnalogVoltageSelection(void);
void HAL_SYSCFG_DisableIOAnalogVoltageSelection(void);

void HAL_SYSCFG_SetAnalogIOSwitchSupply(hal_syscfg_analog_switch_t analog_switch);
