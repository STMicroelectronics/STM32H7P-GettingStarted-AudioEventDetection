HAL ADC io operation functions migration ¶

This section provides information about the HAL ADC io operation functions migration.

HAL_ADC_Start ¶

HAL1

HAL2

The function HAL_ADC_Start was responsible for both enabling the ADC and starting the conversion of the regular group:

Functionality:

  • Enable the ADC peripheral.

  • Start the conversion of the regular group.

The functionality has been divided into two separate functions: HAL_ADC_Start and HAL_ADC_REG_StartConv :

Functionality Split:

  1. `HAL_ADC_Start`

    • Activate the ADC instance.

  2. `HAL_ADC_REG_StartConv`

    • Start the conversion on the regular group. 

HAL_ADC_Start

HAL_ADC_Start
HAL_ADC_REG_StartConv

Rational: Activation of the ADC is time consuming, the idea is to allow controlling the conversion start and stop without the need to fully deactivate and activate the ADC

Related use cases: ADC conversion by polling use case

HAL1

HAL2

the function HAL_ADC_Stop was responsible for stopping the ADC conversion of the regular group (and injected channels in case of auto-injection mode) and disabling the ADC peripheral:

Functionality:

  • Stop ADC conversion of the regular group (and injected channels in case of auto-injection mode).

  • Disable the ADC peripheral.

this functionality has been divided into two separate functions: HAL_ADC_Stop and HAL_ADC_REG_StopConv :

Functionality Split:

  1. `HAL_ADC_REG_StopConv`

    • Stop the conversion on the regular group.

  2. `HAL_ADC_Stop`

    • Deactivate the ADC instance.

HAL_ADCEx_MultiModeStop_DMA ¶

HAL1

HAL2

the function HAL_ADCEx_MultiModeStop_DMA was responsible for stopping the ADC conversion in multimode:

Functionality:

  • Stop potential multimode conversion on-going, on regular and injected groups

  • Disable the ADC peripheral if conversions are effectively stopped.

this functionality has been divided into two separate functions: HAL_ADC_MM_REG_StopConv_DMA and HAL_ADC_MM_Stop :

Functionality Split:

  1. `HAL_ADC_MM_REG_StopConv_DMA`

    • Stop conversion on multimode ADC instances group regular.

  2. `HAL_ADC_MM_Stop`

    • Deactivate each ADC handle in the multimode setup.
