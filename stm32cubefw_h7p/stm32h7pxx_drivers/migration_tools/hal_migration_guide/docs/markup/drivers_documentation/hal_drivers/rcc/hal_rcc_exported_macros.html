Clock Recovery System (CRS) Driver Migration ¶

Migration to Dedicated Files ¶

Purpose : The migration aims to separate CRS functionalities from general RCC configurations, allowing developers to access CRS-specific features without navigating through unrelated settings.

File Organization : CRS functionalities are now encapsulated within the files stm32ynxx_llcrs.h , stm32ynxx_halcrs.h , and stm32ynxx_halcrs.c , containing all necessary APIs for configuration, control, and monitoring.
