Pause DMA 

HAL_StatusTypeDef HAL_SPI_DMAPause(SPI_HandleTypeDef *hspi);

The DMA Pause feature is not possible according to the SPI peripheral capability. Given so, the HAL_SPI_DMAPause() is no more available on HAL2.

Stop DMA 

HAL_StatusTypeDef HAL_SPI_DMAStop(SPI_HandleTypeDef *hspi);

Removed from HAL2, use HAL_SPI_Abort(hal_spi_handle_t *hspi) instead.

Resume DMA 

HAL_StatusTypeDef HAL_SPI_DMAResume(SPI_HandleTypeDef *hspi);

The DMA Resume feature is not possible according to the SPI peripheral capability. Given so, the HAL_SPI_DMAResume() is no more available on HAL2.

HAL SPIEx Flush Rx Fifo ¶

HAL1

HAL2 

HAL_StatusTypeDef HAL_SPIEx_FlushRxFifo(const SPI_HandleTypeDef *hspi)

In HAL2, The Rx FIFO flush is automatically handled within the process APIs such as HAL_SPI_Receive and HAL_SPI_TransmitReceive , thus the API HAL_SPIEx_FlushRxFifo is removed from HAL2.
