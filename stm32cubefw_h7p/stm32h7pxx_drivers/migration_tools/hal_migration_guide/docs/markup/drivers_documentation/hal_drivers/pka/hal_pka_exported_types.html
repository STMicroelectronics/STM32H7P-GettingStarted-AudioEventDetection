HAL PKA types migration ¶

This section provides information about the HAL PKA types migration.

HAL PKA callbacks registration ¶

HAL1

HAL2 

typedef enum
{
  HAL_PKA_OPERATION_COMPLETE_CB_ID
  HAL_PKA_ERROR_CB_ID
  HAL_PKA_MSPINIT_CB_ID
  HAL_PKA_MSPDEINIT_CB_ID
} HAL_PKA_CallbackIDTypeDef;

Removed.

Note

The callback registration in HAL2 is handled by specific functions for each PKA event. See HAL PKA callbacks register and unregister functions for more details.

Related concept : Split Global Register callback API to one register API per callback and remove unregister callback API

  • Related concept : Revise and optimize the HAL state machine.

Note

The rest of all structures have been renamed and are related to the following concepts:

  • Replace the “TypeDef” part of every typedef with “_t”.

  • Add HAL_PPP Prefix to All HAL Peripheral APIs (Defines, Macros, Types, and Functions).
