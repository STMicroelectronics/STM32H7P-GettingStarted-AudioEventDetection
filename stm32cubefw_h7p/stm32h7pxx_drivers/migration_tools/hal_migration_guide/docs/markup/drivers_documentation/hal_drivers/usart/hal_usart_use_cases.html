HAL USART typical use cases for migration ¶

Note

The processes for transmitting and receiving data using polling, interrupt or DMA are the same in HAL1 and HAL2, except for the specification of buffer size: HAL1 uses Size for the number of data elements (u8 or u16), while HAL2 uses Size_byte for the buffer size in bytes.

 HAL_USART_Receive(&husart, aRxBuffer,

HAL_USART_Transmit(&husart, aTxBuffer,

uint8_t aTxBuffer[] = " **** USART_SlaveMode **** ";

HAL_USART_Init(&husart, HAL_USART1)

/* add config for usart instance */
HAL_USART_SetConfig(&husart, &my_config)

                          aRxBuffer, DATA_TO_SEND_SIZE, 100)
