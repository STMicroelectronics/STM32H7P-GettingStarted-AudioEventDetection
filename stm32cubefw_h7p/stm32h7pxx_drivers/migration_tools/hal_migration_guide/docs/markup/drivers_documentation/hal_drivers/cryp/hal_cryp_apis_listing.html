HAL CRYP APIs listing for migration ¶

This section provides a full listing of the HAL1 APIs for migration. It includes the various constants, enumerations, structures, functions, and macros.

In HAL2, the HAL CRYP driver is split into HAL CRYP driver for CRYP peripheral and HAL AES driver for AES peripheral, as shown in the table below.

peripheral

HAL1 driver

HAL2 driver

AES

SAES

HAL CRYP

HAL AES

CRYP

HAL CRYP

HAL CRYP

In the tables below, CRYP refers to the CRYP peripheral APIs in the HAL1 CRYP driver, and AES refers to the AES peripheral APIs in the same driver.

In the common sections, you can select the Refer to option to specify which peripheral is to be used.
