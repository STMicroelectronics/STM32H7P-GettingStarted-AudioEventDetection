Welcome to the HAL1 to HAL2 migration guide ¶

Welcome to the user guide for migrating your software application from STM32Cube HAL version 1 to STM32Cube HAL2. The STM32Cube HAL (hardware abstraction layer) has undergone significant improvements in its latest version, enhancing performance, resources usage, and ease of use. However, these enhancements come with breaking changes that may affect the compatibility of your existing applications.

This guide is designed to assist you in navigating these changes and successfully migrating your application to STM32Cube HAL2.

We provide detailed instructions and best practices to ensure a smooth transition:

  • Getting Started : Introducing the HAL1 to HAL2 Migration Material and Recommended Journey.

  • HAL1 automatic detection script : Discover the HAL1 APIs detection tool Setup and Usage.

  • STM32 Drivers Migration Guides : Learn About HAL2 Changes vs HAL1 in Concepts and Detailed Driver-by-Driver Analysis.

  • Migration example : A Practical Migration Journey on an Example.

  • HAL migration checklist ( link ): Enabling users to monitor their progress and ensure that all steps of the migration journey are completed successfully.
