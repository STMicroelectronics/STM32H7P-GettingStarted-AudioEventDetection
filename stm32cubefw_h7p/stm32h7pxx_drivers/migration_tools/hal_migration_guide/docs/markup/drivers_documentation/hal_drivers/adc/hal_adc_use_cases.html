HAL ADC typical use cases for migration ¶

ADC conversion by polling use case ¶

Description of usage ¶

HAL1

HAL2

Start Conversion

  • Activate the ADC peripheral and start conversions using :

  • HAL_ADC_Start() : For regular group.

  • HAL_ADCEx_InjectedStart : For injected group.

  • Activate the ADC peripheral and start conversions using :

    HAL_ADC_Start() .

Note

From this point, ADC internal analog hardware is enabled, inducing slight current consumption.

  • Start conversion with a trigger using :

    1. HAL_ADC_REG_StartConv() : For Regular group.

    2. HAL_ADC_INJ_StartConv() : For injected group.

Note

Conversion trigger can be:

  • Software start: Function to call for each conversion.

  • From another peripheral (e.g., timer): Function to call once.

Calibration (Optional)

  • Start calibration using HAL_ADCEx_Calibration_Start() .

  • Get calibration value using HAL_ADCEx_Calibration_GetValue() .

  • Set calibration value using HAL_ADCEx_Calibration_SetValue() .

  • Calibrate the ADC using HAL_ADC_Calibrate() .

  • Get calibration factor using HAL_ADC_GetCalibrationFactor() .

  • Set calibration factor using HAL_ADC_SetCalibrationFactor() .

Wait for Conversion Completion

  • Wait for ADC conversion completion using:

  1. HAL_ADC_PollForConversion() :For Regular group.

  2. HAL_ADCEx_InjectedPollForConversion() :For injected group.

    • Note : If using specific events (e.g., ADC_EOSMP_EVENT , ADC_AWD1_EVENT ), use HAL_ADC_PollForEvent() .

  • Poll for conversion completion using:

  1. HAL_ADC_REG_PollForConv() :For Regular group.

  2. HAL_ADC_INJ_PollForConv :For injected group.

    • Note : If using specific events (e.g., ADC_EOSMP_EVENT , ADC_AWD1_EVENT ), use HAL_ADC_PollForEvent() .

Retrieve Conversion Results

  • Retrieve conversion results using :

  1. HAL_ADC_GetValue() :For Regular group.

  2. HAL_ADCEx_InjectedGetValue :For injected group.

  • Retrieve conversion results using :

  1. HAL_ADC_REG_GetValue() :For Regular group.

  2. HAL_ADC_INJ_GetValue :For injected group.

Stop Conversion

  • Stop potential conversion on going and disable the ADC peripheral using :

  1. HAL_ADC_Stop() : On Regular and injected group.

  2. HAL_ADCEx_RegularStop : On Regular group.

  3. HAL_ADCEx_InjectedStop : On injected group.

  • If the conversion trigger is not a software start (e.g., from another peripheral like a timer), stop conversion using:

  1. HAL_ADC_REG_StopConv() :For Regular group.

  2. HAL_ADC_INJ_StopConv : For injected group.

  • Stop the ADC using HAL_ADC_Stop() .

Warning

In case of Multiple conversion are needed do not fully stop the ADC Using the function HAL_ADC_Stop()

  1. The split of The Activate and start conversions of the ADC peripheral.

  2. The split of The disable and Stop conversions of the ADC peripheral.

Summary of key changes ¶

  1. The split of The Activate and start conversions in interrupt mode of the ADC peripheral.

  2. The split of The disable and Stop conversions in interrupt mode of the ADC peripheral.

  3. In HAL2 use HAL_ADC_REG_StartConv_IT_Opt() instead of HAL_ADC_REG_StartConv_IT() to enable only specific interruption example :

    • EOC and AWD1 interruption.

ADC conversion mode DMA use case ¶

Description of usage ¶

HAL1

HAL2

Start Conversion in DMA Mode

Activate the ADC peripheral and start conversions in DMA mode using HAL_ADC_Start_DMA() . Specify the buffer where the ADC data will be stored and the length of the buffer.

  • Activate the ADC peripheral and start conversions using HAL_ADC_Start() .

Note

From this point, ADC internal analog hardware is enabled, inducing slight current consumption.

  • Start conversion with a trigger using HAL_ADC_REG_StartConv_DMA() .

Note

Conversion trigger can be:

  • Software start: Function to call for each conversion.

  • From another peripheral (e.g., timer): Function to call once.

Calibration (Optional)

  • Start calibration using HAL_ADCEx_Calibration_Start() .

  • Get calibration value using HAL_ADCEx_Calibration_GetValue() .

  • Set calibration value using HAL_ADCEx_Calibration_SetValue() .

  • Calibrate the ADC using HAL_ADC_Calibrate() .

  • Get calibration factor using HAL_ADC_GetCalibrationFactor() .

  • Set calibration factor using HAL_ADC_SetCalibrationFactor() .

DMA Transfer Complete Callback

Implement the callback HAL_ADC_ConvCpltCallback() which will be called when the DMA transfer is complete. This callback function will handle the completed conversion.

Implement the callback HAL_ADC_REG_DataTransferCpltCallback() which will be called when the DMA transfer is complete. This callback function will handle the completed conversion.

DMA Half-Transfer Callback

Implement the callback HAL_ADC_ConvHalfCpltCallback() which will be called when the DMA half-transfer is complete. This callback function will handle the half-completed conversion.

Implement the callback HAL_ADC_REG_DataTransferHalfCallback() which will be called when the DMA half-transfer is complete. This callback function will handle the half-completed conversion.

Retrieve Conversion Results

The conversion results are stored in the buffer specified in HAL_ADC_Start_DMA() . You can process the data in the DMA transfer complete and half-transfer complete callbacks.

The conversion results are stored in the buffer specified in HAL_ADC_REG_StartConv_DMA() . You can process the data in the DMA transfer complete and half-transfer complete callbacks.

Stop Conversion

  • Stop potential conversion on going, on ADC groups regular and injected and disable the ADC peripheral using : - HAL_ADC_Stop_DMA() .

  • Stop potential conversion on going, on ADC groups regular and disable the ADC peripheral using : - HAL_ADCEx_RegularStop_DMA() .

  • If the conversion trigger is not a software start (e.g., from another peripheral like a timer), stop conversion using HAL_ADC_REG_StopConv_DMA() .

  • Stop the ADC using HAL_ADC_Stop() .

ADC conversion in multi-mode DMA use case ¶

Description of usage ¶

HAL1

HAL2

Start Conversion in Multi-Mode DMA

Activate the ADC peripherals and start conversions in multi-mode DMA using HAL_ADCEx_MultiModeStart_DMA() . Specify the buffer where the ADC data will be stored and the length of the buffer.

  • Activate the ADC peripheral and start conversions using HAL_ADC_MM_Start() .

Note

From this point, ADC internal analog hardware is enabled, inducing slight current consumption.

  • Start conversion with a trigger using :

    1. HAL_ADC_MM_REG_StartConv_DMA() : Single DMA Channel for all ADC instances.

    2. HAL_ADC_MM_REG_StartConvM_DMA() : DMA Channel for each ADC instances.

Note

Conversion trigger can be:

  • Software start: Function to call for each conversion.

  • From another peripheral (e.g., timer): Function to call once.

Calibration (Optional)

  • Start calibration using HAL_ADCEx_Calibration_Start() .

  • Get calibration value using HAL_ADCEx_Calibration_GetValue() .

  • Set calibration value using HAL_ADCEx_Calibration_SetValue() .

  • Calibrate each ADC using HAL_ADC_Calibrate() or all using HAL_ADC_MM_Calibrate() .

  • Get calibration factor using HAL_ADC_GetCalibrationFactor() .

  • Set calibration factor using HAL_ADC_SetCalibrationFactor() .

DMA Transfer Complete Callback

Implement the callback HAL_ADC_ConvCpltCallback() which will be called when the DMA transfer is complete. This callback function will handle the completed conversion.

Implement the callback HAL_ADC_REG_DataTransferCpltCallback() which will be called when the DMA transfer is complete. This callback function will handle the completed conversion.

DMA Half-Transfer Callback

Implement the callback HAL_ADC_ConvHalfCpltCallback() which will be called when the DMA half-transfer is complete. This callback function will handle the half-completed conversion.

Implement the callback HAL_ADC_REG_DataTransferHalfCallback() which will be called when the DMA half-transfer is complete. This callback function will handle the half-completed conversion.

Retrieve Conversion Results

Use HAL_ADCEx_MultiModeGetValue() to retrieve the conversion results. This function can be called within the DMA transfer complete callback to get the combined result of the master and slave ADCs.

The conversion results are stored in the buffer specified in HAL_ADC_REG_StartConv_DMA() . You can process the data in the DMA transfer complete and half-transfer complete callbacks.

Stop Conversion

Stop potential conversion on going, on ADC groups regular and injected and disable the ADC peripherals using HAL_ADCEx_MultiModeStop_DMA() .

  • If the conversion trigger is not a software start (e.g., from another peripheral like a timer), stop conversion using HAL_ADC_MM_REG_StopConv_DMA() .

  • Stop the ADC using HAL_ADC_MM_Stop() .
