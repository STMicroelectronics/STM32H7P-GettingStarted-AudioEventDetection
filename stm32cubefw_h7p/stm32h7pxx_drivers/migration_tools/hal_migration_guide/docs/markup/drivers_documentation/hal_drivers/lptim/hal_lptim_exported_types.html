HAL LPTIM types migration ¶

This section provides information about the HAL LPTIM types migration.

LPTIM active channel identifiers ¶

HAL1

HAL2 

typedef enum
{
  HAL_LPTIM_ACTIVE_CHANNEL_1       ,
  HAL_LPTIM_ACTIVE_CHANNEL_2       ,
  HAL_LPTIM_ACTIVE_CHANNEL_CLEARED ,
} HAL_LPTIM_ActiveChannel;

Removed

Note

In HAL1, the enumeration is used to determine the active channel within the callback by reading the field channel of the LPTIM_TypeDef handle.

In HAL2, the enumeration is removed and the active channel is now an argument of type hal_lptim_channel_t in all channel related callbacks.

LPTIM_ULPClockConfigTypeDef structure type Definition ¶

Note

  • In HAL1, the LPTIM_ULPClockConfigTypeDef structure is used to configure the external clock source for the LPTIM peripheral, specifically through the input1 . The user could select the clock source by setting the Input1Source parameter in the initialization structure

  • In HAL2, To configure the external clock source through the input1, we have the structure hal_lptim_input1_config_t which includes an enumeration for the input1 source, as well as separate fields for polarity and filter (sample time). Additionally, we have the following new APIs to configure the input1:

    • A global configuration API HAL_LPTIM_SetConfigInput1() function to set all parameters at Once

    • Unitary configuration APIs:

      • HAL_LPTIM_SetInput1Filter() : To set the input1 filter.

      • HAL_LPTIM_SetInput1Polarity() : To set the input1 polarity.

      • HAL_LPTIM_SetInput1Source() : To set the input1 source.
