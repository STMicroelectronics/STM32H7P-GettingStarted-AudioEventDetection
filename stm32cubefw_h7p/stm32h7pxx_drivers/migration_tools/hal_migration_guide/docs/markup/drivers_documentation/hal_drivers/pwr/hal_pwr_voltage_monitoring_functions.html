HAL PWR Configure PVD ¶

HAL1

HAL2

Function name

  • HAL_PWR_ConfigPVD() OR HAL_PWREx_ConfigPVD

  • in HAL2, use the following sequence to configure PVD 

/* Set PLS[7:5] bits according to PVDLevel value */
HAL_PWR_SetProgrammableVoltageDetectorLevel(level)

  • for the EXTI management use the hal EXTI instead to initialize , configure and enable the corresponding exti line .

    Related use case Power Voltage Detector (PVD) with EXTI wakeup

HAL PWR Configure PVM ¶

HAL1

HAL2

Function name

  • HAL_PWR_ConfigPVM()

  • In HAL2, the PVM configuration is managed using the EXTI driver. For EXTI management, use the HAL EXTI instead to initialize, configure, and enable the corresponding EXTI line.

    Related use case Power Voltage Detector (PVD) with EXTI wakeup .
