HAL GENERIC Typical Use Cases for Migration ¶

Important

The most significant change for the HAL GENERIC driver is its split into four distinct dedicated drivers:

  • GENERIC

  • SYSCFG/SBS

  • DBGMCU

  • VREFBUF

This restructuring enhances modularity and clarity, allowing for more focused and maintainable code management.

Summary of Key Changes ¶

Key Change

Description

Consolidation of Tick Functions

In HAL2, the functions to set tick frequency and interrupt priority have been merged into a single function HAL_InitTick .

Summary of Key Changes ¶

Key Change

Description

Consolidation of Device ID Functions

In HAL2, the functions to get device and revision IDs have been moved to the DBGMCU driver.

Consolidation of Unique Device ID Functions

In HAL2, the functions to get parts of the unique device ID have been merged into a single function HAL_GetDeviceUniqueID .

Introduction of HAL Version Function

In HAL2, the function HAL_GetVersion replaces HAL_GetHalVersion .

int main(void)
{
    HAL_Init();
    /*
    ...
    */

    /* Set Voltage Scaling */
    HAL_SYSCFG_VREFBUF_VoltageScalingConfig(SYSCFG_VREFBUF_VOLTAGE_SCALE0);

    /* Configure the high impedance mode */
    HAL_SYSCFG_VREFBUF_HighImpedanceConfig(SYSCFG_VREFBUF_HIGH_IMPEDANCE_ENABLE);

    /* Enable VREFBUF */
    HAL_SYSCFG_EnableVREFBUF();
}

int main(void)
{
    HAL_Init();
    /*
    ...
    */
    hal_vrefbuf_config_t p_config;

    p_config.mode = HAL_VREFBUF_MODE_EXT_VOLTAGE_REF;
    p_config.voltage_scale = HAL_VREFBUF_VOLTAGE_SCALE0;

    /* Configure and enable VREFBUF (Voltage scale and VREFBUF mode) */
    HAL_VREFBUF_SetConfig(VREFBUF1, &p_config);

}

Important

In HAL2, the configuration and enable functions for VREFBUF have been merged into HAL_VREFBUF_SetConfig , which configures and enables the VREFBUF for the given mode.
