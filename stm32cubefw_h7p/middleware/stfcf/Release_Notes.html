Purpose

  • The STM32 Flexible Crypto Framework (aka STFCF) is an STMicroelectronics initiative providing users with several crypto implementations in a flexible way by configuring the required algorithm and implementation.
  • The following implementations are supported:
    • MbedTLS ALT for HAL
    • MbedTLS ALT for STCryptoLib
    • MbedTLS
    • Key Wrapping Engine (aka KWE)

Known Limitations

  • KWE: Add Key Wrap Engine (KWE) as a supported PSA driver
  • Mbed TLS Alt:
    • Rename aes_alt.c, ccm_alt.c and gcm_alt.c into aes_aes_alt.c, aes_ccm_alt.c and aes_gcm_alt.c respectively to indicate which peripheral is used for AES algorithms.
    • Add cryp_aes_alt.c, cryp_ccm_alt.c, and cryp_gcm_alt.c drivers to support AES algorithms through CRYP peripheral.

Main Changes

  • Update license terms to SLA0078

Dependencies

  • MbedTLS 3.6.3 minimum

Main Changes

  • First proposed version of STFCF allowing configuration and code generation.
  • The following features are provided:
    • MbedTLS ALT for HAL offering the following algorithms:
      • ALT AES
      • ALT CCM
      • ALT GCM
      • ALT RSA
      • ALT SHA-1
      • ALT SHA-2
      • ALT ECDSA
      • ALT ECDH
      • ALT ECP
    • MbedTLS ALT STCryptoLib (ST SW library)
    • MbedTLS implementation
    • MbedTLS ALT custom (user customization)

Contents

  • mbedtls_alt drivers: STMicroelectronics implementation to MbedTLS ALT for HW acceleration.
  • templates: proposed default configurations for MbedTLS and MbedTLS ALT.

Known Limitations

  • Rename aes_alt.c, ccm_alt.c and gcm_alt.c into aes_aes_alt.c, aes_ccm_alt.c and aes_gcm_alt.c respectively to indicate which peripheral is used for AES algorithms.
  • Add cryp_aes_alt.c, cryp_ccm_alt.c, and cryp_gcm_alt.c drivers to support AES algorithms through CRYP peripheral.
