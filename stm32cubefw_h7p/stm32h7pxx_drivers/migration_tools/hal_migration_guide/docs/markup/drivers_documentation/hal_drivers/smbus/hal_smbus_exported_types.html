HAL SMBUS types migration ¶

This section provides information about the HAL SMBUS types migration.

HAL SMBUS callback enumeration type Definition ¶

HAL1

HAL2 

typedef enum
{
  HAL_SMBUS_MASTER_TX_COMPLETE_CB_ID,
  HAL_SMBUS_MASTER_RX_COMPLETE_CB_ID,
  HAL_SMBUS_SLAVE_TX_COMPLETE_CB_ID,
  HAL_SMBUS_SLAVE_RX_COMPLETE_CB_ID,
  HAL_SMBUS_LISTEN_COMPLETE_CB_ID,
  HAL_SMBUS_ERROR_CB_ID,
  HAL_SMBUS_ABORT_CB_ID,
  HAL_SMBUS_MSPINIT_CB_ID,
  HAL_SMBUS_MSPDEINIT_CB_ID
} HAL_SMBUS_CallbackIDTypeDef;

Removed. The callback registration in HAL2 is handled by specific functions for each SMBUS event. For more details, see : HAL SMBUS callbacks register and unregister functions

HAL_SMBUS_MSPINIT_CB_ID and HAL_SMBUS_MSPDEINIT_CB_ID are removed because the functions HAL_SMBUS_MspInit() and HAL_SMBUS_MspDeInit() are removed.

Related concept :

  • Split Global Register callback API to one register API per callback and remove unregister callback API

  • Remove MspInit and MspDeInit callbacks

HAL SMBUS mode enumeration type definition ¶

HAL1

HAL2

In HAL1, this enumeration is used in some series only, the majority of series used SMBUS peripheral modes constants .

In HAL2, only one single enumeration used SMBUS peripheral modes constants . 

typedef enum
{
  HAL_SMBUS_MODE_NONE /* No communication on going */
  HAL_SMBUS_MODE_MASTER
  HAL_SMBUS_MODE_SLAVE
} HAL_SMBUS_ModeTypeDef;

typedef enum
{
 /* MODE NONE removed */
  HAL_SMBUS_PERIPHERAL_MODE_HOST
  HAL_SMBUS_PERIPHERAL_MODE_SLAVE      /* SMBUS Slave default mode                */
  HAL_SMBUS_PERIPHERAL_MODE_SLAVE_ARP  /* SMBus Slave Default address acknowledge */
} hal_smbus_mode_t;
