HAL SMARTCARD constants migration ¶

This section provides information about the HAL SMARTCARD constants migration .

HAL SMARTCARD error codes constants ¶

HAL1

HAL2

In HAL1, error handling is performed using a set of macros that define various error states, including combined errors such as HAL_SMARTCARD_ERROR_DMA .

In HAL2, the error defines are reorganized and renamed.

  • The HAL_SMARTCARD_ERROR_DMA are split into separate transmit and receive error defines.

  • The HAL_SMARTCARD_ERROR_INVALID_CALLBACK is removed. for more details see HAL_SMARTCARD_GetError

  • The HAL_SMARTCARD_TRANSMIT_ERROR_NACK constant is added to detect transmission errors due to NACK. 

#define HAL_SMARTCARD_ERROR_NONE
#define HAL_SMARTCARD_ERROR_PE
#define HAL_SMARTCARD_ERROR_NE
#define HAL_SMARTCARD_ERROR_FE
#define HAL_SMARTCARD_ERROR_ORE
#define HAL_SMARTCARD_ERROR_RTO
#define HAL_SMARTCARD_ERROR_DMA


#define HAL_SMARTCARD_ERROR_INVALID_CALLBACK

#define HAL_SMARTCARD_ERROR_NONE
#define HAL_SMARTCARD_RECEIVE_ERROR_PE
#define HAL_SMARTCARD_RECEIVE_ERROR_NE
#define HAL_SMARTCARD_RECEIVE_ERROR_FE
#define HAL_SMARTCARD_RECEIVE_ERROR_ORE
#define HAL_SMARTCARD_RECEIVE_ERROR_RTO
#define HAL_SMARTCARD_RECEIVE_ERROR_DMA
#define HAL_SMARTCARD_TRANSMIT_ERROR_DMA
#define HAL_SMARTCARD_TRANSMIT_ERROR_NACK

  1. Renaming of several states.

HAL SMARTCARD advanced feature initialization constants ¶

HAL1

HAL2 

#define SMARTCARD_ADVFEATURE_NO_INIT
#define SMARTCARD_ADVFEATURE_DATAINVERT_INIT
#define SMARTCARD_ADVFEATURE_DMADISABLEONERROR_INIT
#define SMARTCARD_ADVFEATURE_RXINVERT_INIT
#define SMARTCARD_ADVFEATURE_RXOVERRUNDISABLE_INIT

#define SMARTCARD_ADVFEATURE_SWAP_INIT
#define SMARTCARD_ADVFEATURE_MSBFIRST_INIT
#define SMARTCARD_ADVFEATURE_TXCOMPLETION

These constants are removed because the structure SMARTCARD_AdvFeatureInitTypeDef that used these defines in HAL1 is removed.

Each advanced feature is now configured and controlled through specific functions, allowing direct management of these features without relying on the previous structure.

Note

  • In HAL2, the advanced MSB First feature is incorporated into the smartcard configuration structure hal_smartcard_config_t through the first_bit parameter.

  • The advanced RX inversion feature is removed as only one line is used for both transmission (TX) and reception (RX).
