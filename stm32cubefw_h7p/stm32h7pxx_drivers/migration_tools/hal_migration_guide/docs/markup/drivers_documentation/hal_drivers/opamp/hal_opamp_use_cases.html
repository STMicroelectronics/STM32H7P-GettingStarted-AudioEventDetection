HAL OPAMP Typical use cases for migration ¶

This section provides information about the HAL OPAMP Typical use cases for migration.

HAL OPAMP in PGA mode ¶

This use case employs the OPAMP (operational amplifier) in PGA (Programmable Gain Amplifier) mode to boost a differential analog signal. The amplified output is then digitized by the ADC (Analog-to-Digital Converter) for further processing.

  • Set instance, mode, inputs, gain, trimming

  • HAL_OPAMP_Init()

  • HAL configures OPAMP1 peripheral and gain to 2 (PGA mode)

  • HAL_OPAMP_Init()

    hconfig_input.inverting_input = HAL_OPAMP_INVERTING_INPUT_GPIO_1;

        Error_Handler();

        Error_Handler();

    hadc1.Init.Resolution = HAL_ADC_RESOLUTION_12_BIT;

    if (HAL_ADC_SetConfigPostProcessing(hadc, &adc_config_post_processing) != HAL_OK)
    {
        Error_Handler();
    }

    adc_config_low_power.lp_auto_wait = HAL_ADC_LP_AUTO_WAIT_DISABLE;
    if (HAL_ADC_SetConfigLowPower(hadc, &adc_config_low_power) != HAL_OK)
    {
        Error_Handler();
    }

        Error_Handler();

    adc_channel_config.sampling_time = HAL_ADC_SAMPLING_TIME_247CYCLES_5;

        Error_Handler();
