HAL GFXMMU types migration ¶

This section provides information about the HAL GFXMMU types migration.

HAL GFXMMU address cache structure type definition ¶

HAL1

HAL2

In HAL1, this structure is used with :

  • the GFXMMU_InitTypeDef structure and HAL_GFXMMU_Init function : to enable or disable the address cache with providing the buffer on which the address cache is locked.

  • the HAL_GFXMMU_ModifyAddressCache function: to change the address cache settings already configured in HAL_GFXMMU_Init .

In HAL2, the address cache is enabled or disabled by unitary functions in the HAL layer.

hal_gfxmmu_buff_t buff is to select the buffer index 

typedef struct
{
  FunctionalState Activation;


  uint32_t AddressCacheLockBuffer;


 } GFXMMU_AddressCacheTypeDef;

/* */

 hal_status_t HAL_GFXMMU_EnableCache(hal_gfxmmu_handle_t *hgfxmmu);
 hal_status_t HAL_GFXMMU_DisableCache(hal_gfxmmu_handle_t *hgfxmmu);

 hal_status_t HAL_GFXMMU_EnableCacheLockBuff(hal_gfxmmu_handle_t *hgfxmmu,
                                             hal_gfxmmu_buff_t buff);
 hal_status_t HAL_GFXMMU_DisableCacheLockBuff(hal_gfxmmu_handle_t *hgfxmmu);

HAL GFXMMU Interrupts structure type definition ¶

HAL1

HAL2

In HAL1, the GFXMMU interrupt is a member of the GFXMMU_InitTypeDef structure. 

typedef struct
{
   FunctionalState Activation;
   uint32_t        UsedInterrupts;
} GFXMMU_InterruptsTypeDef

Removed : In HAL2, the GFXMMU interrupt is managed by static inline functions in the HAL layer. 

/* */


 void HAL_GFXMMU_EnableIT(hal_gfxmmu_handle_t *hgfxmmu, uint32_t it_source);
 void HAL_GFXMMU_DisableIT(hal_gfxmmu_handle_t *hgfxmmu, uint32_t it_source);

Usage example: 

/* Interrupts parameters enabled */
GFXMMU_HandleTypeDef GfxmmuHandle = {
.Init.Interrupts.Activation     = ENABLE;
.Init.Interrupts.UsedInterrupts = GFXMMU_BUFFER0_OVERFLOW_IT;
};
HAL_GFXMMU_Init(&GfxmmuHandle);

/* Interrupts parameters disabled */
.Init.Interrupts.Activation  = Disable;
HAL_GFXMMU_Init(&GfxmmuHandle);

Usage example: 

/* Interrupts parameters enabled */
 HAL_GFXMMU_EnableIT(&hgfxmmu, HAL_GFXMMU_IT_BUFF0_OVERFLOW);




/* Interrupts parameters disabled */
 HAL_GFXMMU_DisableIT(&hgfxmmu);

HAL GFXMMU Lut Line structure type definition ¶

HAL1

HAL2

In HAL1, GFXMMU_LutLineTypeDef structure is used to configure one line of the LUT with HAL_GFXMMU_ConfigLutLine function. 

typedef struct
{
  uint32_t LineNumber;
  uint32_t LineStatus;
  uint32_t FirstVisibleBlock;
  uint32_t LastVisibleBlock;
  uint32_t LineOffset;
} GFXMMU_LutLineTypeDef;

Removed:

In HAL2, this structure is no more available, the user cannot configure one line of the LUT. Now, you can use hal_gfxmmu_lut_config_t structure with HAL_GFXMMU_SetLUT function to configure all lines of the LUT.

For more details, see HAL GFXMMU configure the lookup table (LUT)

HAL GFXMMU state enumeration type definition ¶

  • In HAL2, the state machine of the GFXMMU is split into three separate state machines:

    • Global state machine: driver global process

    • Lut state machine : LUT subprocess

    • Buffer state machine: buffer subprocess

HAL2
