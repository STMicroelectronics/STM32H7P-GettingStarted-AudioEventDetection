HAL1 CRYP –> HAL2 AES ¶

This section provides information about the HAL AES constants migration .

Error code ¶

HAL1

HAL2 

#define HAL_CRYP_ERROR_NONE

#define HAL_AES_ERROR_NONE

#define HAL_CRYP_WRITE_ERROR
/* or  */
#define HAL_CRYP_ERROR_WRITE

#define HAL_AES_ERROR_WRITE

#define HAL_CRYP_READ_ERROR
/* or  */
#define HAL_CRYP_ERROR_READ

#define HAL_AES_ERROR_READ

#define HAL_CRYP_ERROR_KEY

#define HAL_AES_ERROR_KEY

#define HAL_CRYP_ERROR_RNG

#define HAL_AES_ERROR_RNG

#define HAL_CRYP_DMA_ERROR
/* or  */
#define HAL_CRYP_ERROR_DMA

#define HAL_AES_ERROR_DMA

#define HAL_CRYP_BUSY_ERROR
#define HAL_CRYP_ERROR_BUSY
#define HAL_CRYP_ERROR_TIMEOUT
#define HAL_CRYP_ERROR_NOT_SUPPORTED
#define HAL_CRYP_ERROR_AUTH_TAG_SEQUENCE
#define HAL_CRYP_ERROR_INVALID_CALLBACK

Removed : These kinds of logical errors are reported by the direct function return.

Algorithm / chaining mode ¶

HAL1

HAL2 

#define  CRYP_CHAINMODE_AES_ECB
#define  CRYP_AES_ECB
#define  CRYP_CHAINMODE_AES_CBC
#define  CRYP_AES_CBC
#define  CRYP_CHAINMODE_AES_CTR
#define  CRYP_AES_CTR
#define  CRYP_CHAINMODE_AES_GCM_GMAC
#define  CRYP_AES_GCM_GMAC
#define  CRYP_AES_GCM
#define  CRYP_CHAINMODE_AES_CCM
#define  CRYP_AES_CCM
#define  CRYP_CHAINMODE_AES_CMAC

Removed : In HAL2, The global set configuration was split into one configuration function per algorithm,

so there is no need to specify the algorithm.

DMA input phase management constants ¶

HAL1

HAL2 

#define  CRYP_DMAIN_ENABLE
#define  CRYP_DMAOUT_ENABLE
#define  CRYP_DMAOUT_DISABLE
#define  CRYP_DMAIN_DISABLE

Removed : In HAL2, all DMA input phase management is used only internally

and does not need to be exported.

GCM/GMAC and CCM/CMAC processing phase constants ¶

HAL1

HAL2 

#define CRYP_GCM_INIT_PHASE
#define CRYP_GCMCMAC_HEADER_PHASE
#define CRYP_GCM_PAYLOAD_PHASE
#define CRYP_GCMCMAC_FINAL_PHASE
#define CRYP_INIT_PHASE
#define CRYP_HEADER_PHASE
#define CRYP_PAYLOAD_PHASE
#define CRYP_FINAL_PHASE

Removed : In HAL2, processing phases are removed from global configuration function

and are only used internally, so they dont need to be exported.

Enable state constants ¶

HAL1

HAL2 

#define CRYP_AES_DISABLE
#define CRYP_AES_ENABLE

Removed : In HAL2, state constants are used only internally

and does not need to be exported.

Operating mode constants ¶

HAL1

HAL2 

#define CRYP_ALGOMODE_ENCRYPT
#define CRYP_ALGOMODE_KEYDERIVATION
#define CRYP_ALGOMODE_DECRYPT
#define CRYP_ALGOMODE_KEYDERIVATION_DECRYPT
#define CRYP_ALGOMODE_TAG_GENERATION

Removed : In HAL2, all operating mode constants are removed from global configuration function

 and set within the encryption or decryption functions.

Key and init vector configuration skip mode constants ¶

HAL1

HAL2 

#define CRYP_KEYIVCONFIG_ALWAYS
#define CRYP_KEYIVCONFIG_ONCE
#define CRYP_KEYNOCONFIG
#define CRYP_IVCONFIG_ONCE

Removed: In HAL2, the AES key is no longer part of the global configuration function.

Instead, it is utilized when invoking the HAL_AES_SetNormalKey(), HAL_AES_SetSharedKey(),

HAL_AES_SetHWKey() functions. Similarly, the initialization vector has been removed from

the global configuration function and is now used when calling specific set configuration functions.

Data width unit constants ¶

HAL1

HAL2 

#define CRYP_DATAWIDTHUNIT_WORD
#define CRYP_DATAWIDTHUNIT_BYTE

Removed: In HAL2, the data size used in all process functions is byte

and data width has been removed from global configuration.

Header width unit constants ¶

HAL1

HAL2 

#define CRYP_HEADERWIDTHUNIT_WORD
#define CRYP_HEADERWIDTHUNIT_BYTE

Removed: In HAL2, the header size used in configuration functions is byte

and header width has been removed from global configuration.
