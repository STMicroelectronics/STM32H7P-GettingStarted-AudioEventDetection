HAL CORTEX migration: List of applicable concepts ¶

This section provides information about the HAL CORTEX applicable concepts .

concepts for CORTEX ¶

Concept

Description

Add unitary configuration APIs

Unitary APIs will be added mainly in the MPU section to provide more control for the configuration.

Remove single or double underscore prefixes from any define or macro, as this is not allowed per the C standard.

Ensure that all defines and macros adhere to the C standard by avoiding the use of single or double underscore prefixes, which are reserved for compiler and standard library use.

Replace the “TypeDef” part of every typedef with “_t”.

For example: MPU_Region_InitTypeDef -> mpu_region_init_t.

Remove underscore prefixes from header file guards and replace them with #ifndef HAL_PPP_HDR_H (use _HDR_H suffix).

Update header file guards to remove underscore prefixes and use a consistent naming convention with the “_HDR_H” suffix, ensuring compatibility with the C standard.

For example: __STM32ynxx_HAL_CORTEX_H -> STM32ynXX_HAL_CORTEX_H

__STM32ynxx_HAL_CORTEX_H -> STM32ynxx_HAL_CORTEX_H

Replace non-modifiable pointers with const keywords.

Enhance code safety and clarity by adding the const keyword to pointers that should not be modified, preventing unintended changes to data.

For example: HAL_MPU_ConfigRegion(const MPU_Region_InitTypeDef *const pMPU_RegionInit)

-> HAL_CORTEX_MPU_SetConfigRegion(hal_cortex_mpu_region_idx_t region_idx, const hal_cortex_mpu_region_config_t *p_config)

Replace parameter and state checks with assertions.

Implement parameter and state checks using assertions to ensure that conditions are met during development and debugging, improving code reliability and maintainability.

Replace the assert_param macro with ASSERT_DBG_PARAM, controlled by the USE_ASSERT_DBG_PARAM conditional.

Introduce a conditional compilation flag USE_ASSERT_DBG_PARAM to enable or disable debug parameter assertions, allowing for flexible debugging and validation.

For example: ASSERT_DBG_PARAM(IS_PRIORITY_GROUP(prio_grp))

Replace Finite Parameter Defines (Including PPP Instances) with Enum Types at HAL Levels.

Replace finite parameters, such as peripheral instances, with enumerated types at the HAL level to improve type safety, readability, and maintainability.

Other HAL CORTEX changes ¶

ARM Architecture

Concept

Consideration

All

Remove LL CORTEX

Redundant functionality between LL driver and ARM CMSIS core APIs.

All

Add  HAL_CORTEX_NVIC_GetPriority() symmetric API with HAL_CORTEX_NVIC_SetPriority()

Introduce a symmetric API to retrieve the priority of an interrupt, complementing the existing API to set the priority, ensuring consistency and completeness in the NVIC API set.

All

Merge systick clock source configuration HAL_CORTEX_SYSTICK_CLKSourceConfig() with global systick enabling HAL_CORTEX_SYSTICK_Config()

Add source clock as parameter to the  hal_cortex_systik_clk_src_t enumeration.

All

Replace Ticks_num (expressed in time) by ticks_freq (expressed in frequency).

Update the SysTick configuration to use frequency-based parameters instead of time-based parameters, providing a more intuitive and consistent approach to configuring the SysTick timer.

All

Remove unapplicable ARM cortex attributes within STM32 devices.

Remove shareability attribute, transient attribute and L2 cache configuration.

All

Add APIs to be used in memory protection unit (MPU).

HAL_CORTEX_MPU_IsEnabled(), HAL_CORTEX_MPU_IsEnabledRegion(),

All

Add get CPU ID information providing by ll_cortex.h in HAL1.

HAL_CORTEX_SCB_GetInfo()

All

Split the MPU region configuration from the enable/disable.

HAL_CORTEX_MPU_EnableRegion() to enable a region configuration. HAL_CORTEX_MPU_DisableRegion() to disable a region configuration. HAL_CORTEX_MPU_SetConfigRegion() to set region configuration.

ARMv8-M ARMv7-M

Add  missing APIs in NVIC for IRQ management (provided by core_cm33.h)

HAL_CORTEX_NVIC_IsActiveIRQ(), HAL_CORTEX_NVIC_IsEnabledIRQ(), HAL_CORTEX_NVIC_IsPendingIRQ.

ARMv8-M

Abstract “inner” and “outer” approach.

Simplify the configuration of memory attributes by abstracting the “inner” and “outer” approach, making the API more intuitive and easier to use.

ARMv8-M

Split memory attribute API (device configuration vs normal configuration)

Dedicated enumeration for device memory attributes memory:

HAL_CORTEX_MPU_SetDeviceMemAttr(), HAL_CORTEX_MPU_GetDeviceMemAttr().

Dedicated enumeration for normal memory attributes memory:

HAL_CORTEX_MPU_SetCacheMemAttr(), HAL_CORTEX_MPU_GetCacheMemAttr().

ARMv8-M ARMv7-M

Add cortex faults exception management

HAL_CORTEX_SCB_EnableHWFaultEscalation() HAL_CORTEX_SCB_DisableHWFaultEscalation()
