LPTIM Input Capture Source Options Constants ¶

This table lists the input capture sources available in HAL1 and their equivalents in HAL2.

  • In HAL1, there is a set of defines to specify both the input channel (IC1,IC2) and its source (e.g., GPIO, COMP1, COMP2, etc.).

  • In HAL2, these defines are replaced by the hal_lptim_ic_src_t enumeration, which specifies only the source. The channel selection is now passed as a parameter to the HAL_LPTIM_IC_SetConfigChannel function.

HAL1

HAL2 

/**/

 #define LPTIM_IC1SOURCE_GPIO

 #define LPTIM_IC1SOURCE_COMP1

 #define LPTIM_IC1SOURCE_COMP2

 #define LPTIM_IC1SOURCE_EVENTOUT

 #define LPTIM_IC1SOURCE_MCO1

 #define LPTIM_IC1SOURCE_MCO2

 #define LPTIM_IC2SOURCE_CSI_128

 #define LPTIM_IC2SOURCE_GPIO

 #define LPTIM_IC2SOURCE_HSE_1M

 #define LPTIM_IC2SOURCE_HSI_1024

 #define LPTIM_IC2SOURCE_HSI_256

 #define LPTIM_IC2SOURCE_HSI_8

 #define LPTIM_IC2SOURCE_LSE

 #define LPTIM_IC2SOURCE_LSI

 #define LPTIM_IC2SOURCE_MSIS_1024

 #define LPTIM_IC2SOURCE_MSIS_4

typedef enum
{
  HAL_LPTIM_INPUT_GPIO

  HAL_LPTIM_INPUT_COMP1

  HAL_LPTIM_INPUT_COMP2

  HAL_LPTIM_INPUT_EVENTOUT

  HAL_LPTIM_INPUT_MCO1

  HAL_LPTIM_INPUT_MCO2

  HAL_LPTIM_INPUT_CSI_128



  HAL_LPTIM_INPUT_RCC_HSE_1MHZ

  HAL_LPTIM_INPUT_HSI_1024

  HAL_LPTIM_INPUT_HSI_256

  HAL_LPTIM_INPUT_HSI_8

  HAL_LPTIM_INPUT_LSE

  HAL_LPTIM_INPUT_LSI

  HAL_LPTIM_INPUT_MSIS_1024

  HAL_LPTIM_INPUT_MSIS_4

} hal_lptim_ic_src_t;

LPTIM Interrupt Identifiers Constants ¶

HAL1

HAL2 

#define LPTIM_IT_ARRM
#define LPTIM_IT_ARROK
#define LPTIM_IT_CC1
#define LPTIM_IT_CC1O
#define LPTIM_IT_CC2
#define LPTIM_IT_CC2O
#define LPTIM_IT_CMP1OK
#define LPTIM_IT_CMP2OK
#define LPTIM_IT_DOWN
#define LPTIM_IT_EXTTRIG
#define LPTIM_IT_REPOK
#define LPTIM_IT_UP
#define LPTIM_IT_UPDATE
#define LPTIM_IT_CMPM
#define LPTIM_IT_CMPOK

  • In HAL1, those defines are used by the __HAL_LPTIM_ENABLE_IT(__HANDLE__, __INTERRUPT__) `` , ``__HAL_LPTIM_DISABLE_IT(__HANDLE__, __INTERRUPT__) and __HAL_LPTIM_GET_IT_SOURCE(__HANDLE__, __INTERRUPT__) macros.

  • In HAL2, these interrupt defines and macros have been removed. If the user needs to manage interrupts directly, he should use the corresponding LL functions.

    For more details, refer to Enable interrupt macro , Disable interrupt macro and Get interrupt source macro

LPTIM Update Modes Constants ¶

HAL1

HAL2 

#define LPTIM_UPDATE_ENDOFPERIOD
#define LPTIM_UPDATE_IMMEDIATE

In HAL2, the UpdateMode parameter is removed from the Init structure. Instead, the user should call HAL_LPTIM_EnablePreload to enable update mode, or HAL_LPTIM_DisablePreload to disable it.

LPTIM Clock Source and Counter source Options Constants ¶

HAL1

HAL2 

#define LPTIM_CLOCKSOURCE_APBCLOCK_LPOSC /* Internal clock source */
#define LPTIM_CLOCKSOURCE_ULPTIM         /* External clock source */

#define LPTIM_COUNTERSOURCE_INTERNAL
#define LPTIM_COUNTERSOURCE_EXTERNAL

  • In HAL1, the parameters CounterSource and clock are configured independently.

  • In HAL2, we have a single enumeration called hal_lptim_clk_src_t that covers all clocking and counting modes in a more structured way.
