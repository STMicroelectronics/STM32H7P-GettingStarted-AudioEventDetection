HAL CORTEX NVIC functions migration ¶

Note

The NVIC migration functions are divided according to their ARM Architecture. Each Architecture contains multiple CORTEX versions that are used in your STM32 series.

For example:

  • ARMv8-M: CORTEX-M33 (STM32U5…)

  • ARMv7-M: CORTEX-M7, CORTEX-M4 (STM32H7, STM32L4…)

  • ARMv6-M: CORTEX-M0, CORTEX-M0+ (STM32F0, STM32U0…)

You can find your Series in ST website: Link ( https://www.st.com/en/microcontrollers-microprocessors/stm32-32-bit-arm-cortex-mcus.html )

HAL_NVIC_SetPriorityGrouping ¶

ARM Architecture

HAL1

HAL2

The function HAL_NVIC_SetPriorityGrouping is responsible for setting the priority grouping field for the NVIC (Nested Vectored Interrupt Controller):

This function has been renamed to HAL_CORTEX_NVIC_SetPriorityGrouping :

Functionality Update:

  • Use specific enumeration hal_cortex_nvic_priority_group_t for the priority group parameter, enhancing type safety and clarity.

ARMv8-M, ARMv7-M 

void HAL_NVIC_SetPriorityGrouping(uint32_t PriorityGroup)

void HAL_CORTEX_NVIC_SetPriorityGrouping(hal_cortex_nvic_priority_group_t prio_grp)

HAL_NVIC_SetPriority ¶

ARM Architecture

HAL1

HAL2

The function HAL_NVIC_SetPriority is responsible

for setting the priority of an interrupt:

This function has been renamed to HAL_CORTEX_NVIC_SetPriority :

Functionality Update:

  • Use specific enumerations hal_cortex_nvic_preemp_priority_t and hal_cortex_nvic_sub_priority_t for preemption and subpriority parameters, enhancing type safety and clarity.

ARMv8-M, ARMv7-M 

void HAL_NVIC_SetPriority(IRQn_Type IRQn,
                          uint32_t PreemptPriority,
                          uint32_t SubPriority)

void HAL_CORTEX_NVIC_SetPriority(IRQn_Type irqn,
                                 hal_cortex_nvic_preemp_priority_t preemp_prio,
                                 hal_cortex_nvic_sub_priority_t sub_prio)

Functionality Update:

  • Remove the PreemptPriority and SubPriority parameters and replace them with one single parameter using specific enumerations`hal_cortex_nvic_priority_t`.

ARMv6-M 

void HAL_NVIC_SetPriority(IRQn_Type IRQn,
                          uint32_t PreemptPriority,
                          uint32_t SubPriority)

void HAL_CORTEX_NVIC_SetPriority(IRQn_Type irqn,
                                 hal_cortex_nvic_priority_t prio)
