void HAL_COMP_TriggerCallback(COMP_HandleTypeDef *hcomp)
{
  if (hcomp->Instance == COMP1)
  {
    /* Handle the comparator event here */

      /* Comparator output is low */

  }

COMP window mode comparing by interruption use case ¶

Description of usage ¶

HAL1

HAL2

Start comparing

  • Start two comparators in window mode:

  • HAL_COMP_Start_IT(&hcomp1) .

  • HAL_COMP_Start_IT(&hcomp2) .

  • Link the two comparators for window mode using the function HAL_COMP_WINDOW_SetHandle(&hcomp1, &hcomp2)

  • Start two comparators in window mode:

    HAL_COMP_WINDOW_Start_IT(&hcomp1) .

Comparator output Trigger Callback

  • Register the callback using :

    HAL_COMP_RegisterCallback()

  • Or Implement the callback using :

    HAL_COMP_TriggerCallback()

  • Register the callback using :

    HAL_COMP_RegisterOutputTriggerCallback()

  • Or implement the callback using :

    HAL_COMP_OutputTriggerCallback()

Retrieve comparing Result

  • Retrieve comparing results using:

  • HAL_COMP_GetOutputLevel() .

  • Retrieve comparing results using:

  • HAL_COMP_WINDOW_GetOutputLevel() .

Loop for Multiple Iterations

Possible multiple iterations if the comparator output has changed since the last read

Possible multiple iterations if the comparator output has changed since the last read

stop comparing

  • Stop Comparator analog features using:

  • HAL_COMP_Stop_IT(&hcomp1) .

  • HAL_COMP_Stop_IT(&hcomp2) .

  • Stop Comparator analog features using:

    HAL_COMP_WINDOW_Stop_IT(&hcomp1) .

    Note

    Since the two comparators are linked, after calling this function both comparators will be stopped.
