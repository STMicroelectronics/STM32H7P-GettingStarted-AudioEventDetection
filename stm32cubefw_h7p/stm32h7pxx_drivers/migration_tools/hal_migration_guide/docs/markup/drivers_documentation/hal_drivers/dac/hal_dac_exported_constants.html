HAL DAC channel output connection constants ¶

  • In HAL1, some series have the definitions DAC_CHIPCONNECT_EXTERNAL and DAC_CHIPCONNECT_INTERNAL , while others have DAC_CHIPCONNECT_DISABLE and DAC_CHIPCONNECT_ENABLE .

  • In HAL2, DAC_CHIPCONNECT_EXTERNAL and DAC_CHIPCONNECT_INTERNAL become HAL_DAC_OUTPUT_CONNECTION_EXTERNAL and HAL_DAC_OUTPUT_CONNECTION_INTERNAL .

  • In HAL2 DAC_CHIPCONNECT_DISABLE and DAC_CHIPCONNECT_ENABLE become HAL_DAC_OUTPUT_CONNECTION_EXTERNAL and HAL_DAC_OUTPUT_CONNECTION_INTERNAL .

HAL1

HAL2 

/* */

#define DAC_CHIPCONNECT_EXTERNAL
/* or  */
#define DAC_CHIPCONNECT_DISABLE

#define DAC_CHIPCONNECT_INTERNAL
/* or  */
#define DAC_CHIPCONNECT_ENABLE

#define DAC_CHIPCONNECT_BOTH

typedef enum
{
    HAL_DAC_OUTPUT_CONNECTION_EXTERNAL



    HAL_DAC_OUTPUT_CONNECTION_INTERNAL
} hal_dac_output_connection_t ;

Note

DAC_CHIPCONNECT_BOTH was removed: In HAL2, the equivalent is HAL_DAC_OUTPUT_CONNECTION_INTERNAL, as long as the DAC output buffer mode is configured HAL_DAC_OUTPUT_BUFFER_ENABLED.

HAL DAC channel sample and hold mode constants ¶

HAL1

HAL2

In HAL1, the DAC sample and hold mode is a member of the DAC_ChannelConfTypeDef structure.

Removed: In HAL2, the DAC sample and hold mode is managed by unitary functions in the HAL layer.

For more details, refer to HAL DAC channel configuration structure . 

#define DAC_SAMPLEANDHOLD_DISABLE
#define DAC_SAMPLEANDHOLD_ENABLE

HAL_DAC_DisableChannelSampleAndHold(hal_dac_handle_t *hdac, hal_dac_channel_t channel)
HAL_DAC_EnableChannelSampleAndHold(hal_dac_handle_t *hdac, hal_dac_channel_t channel)

HAL DAC user trimming constants ¶

HAL1

HAL2

In HAL1, the DAC user trimming is a member of the DAC_ChannelConfTypeDef structure, which can take the values defined as DAC_TRIMMING_FACTORY and DAC_TRIMMING_USER .

Removed: In HAL2, use HAL_DAC_SetChannelBufferCalibrationValue() with the calibration value, similar to the trimming_value parameter of the DAC_ChannelConfTypeDef structure in HAL1. 

#define DAC_TRIMMING_FACTORY
#define DAC_TRIMMING_USER

HAL_DAC_SetChannelBufferCalibrationValue(&hdac, HAL_DAC_CHANNEL_1, 31);
